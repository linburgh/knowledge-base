# 租户访客问答工作台原型设计

## 页面定位

`tenant_guest` 只访问被授权的知识库并发起问答，不展示知识库管理、文档管理、租户管理和组织管理入口。

页面路径：

```text
/guest/knowledge-bases
/guest/knowledge-bases/:kbId/chat
```

## 页面结构

- 顶部上下文栏：品牌、当前租户、当前用户、租户访客角色和退出登录。
- 页面不设置左侧菜单，避免把受限问答用户置于管理系统导航结构中。
- 左侧工作区：会话列表。
- 中间问答区：顶部授权数据源图标按钮、欢迎提示、问题输入和回答消息。
- 右侧参考资料区：展示回答引用的文档、段落和页码，不展示相似度数值。

## 交互与权限

- 只展示当前用户有权访问的知识库。
- “授权数据源”使用问答区顶部数据库图标按钮触发右侧抽屉，不单独占用大面积列表区域。
- 抽屉列表仅展示知识库名称和描述；支持关键词远程快速查找和分页。
- 点击知识库后切换当前问答范围并自动关闭抽屉。
- 抽屉打开时显示半透明遮罩，点击遮罩或关闭按钮可收起抽屉。
- 抽屉打开时调用 `GET /api/v1/guest/knowledge-bases/page`，使用 `keyword`、`page` 和 `page_size` 查询授权知识库；输入关键词后通过防抖触发远程查询。
- 会话列表提供“新建会话”入口；每个历史会话提供“重命名”和“删除”入口。
- 不展示知识库新建、修改、删除、上传文档、组织授权等管理操作。
- 删除会话前弹出二次确认；重命名使用轻量弹窗或行内编辑，保存后立即刷新会话标题。
- 新建会话后自动选中并清空当前问答内容；切换历史会话时恢复该会话的问答记录。
- Enter 发送问题，Shift+Enter 换行。
- 后端必须再次校验租户角色和知识库授权，前端隐藏不能代替权限校验。

## 视觉方向

使用简洁顶部上下文栏、浅色内容区、蓝色知识库选中态和独立引用面板，突出专业、稳定、可追溯的企业问答体验。

访客问答与知识库问答、分析对话复用同一问答工作区视觉基线：会话、搜索、快捷键、状态和引用辅助文字不低于 13px，问答正文为 14px，面板标题为 16px，聊天标题为 18px。三栏统一使用轻边框、柔和阴影和规整内边距；当前会话、用户消息、助手消息、输入焦点和引用卡片的状态层级不得被访客页面局部样式缩小或覆盖。

## 主流显示器适配规范

### 已识别的问题

- 工作区最大宽度固定为 `1680px`，在 2K（2560×1440）显示器上左右会产生较大的无效留白。
- 会话栏和参考资料栏使用固定宽度，中间问答区没有按屏幕宽度和阅读舒适度进行分配。
- 仅设置了 `1250px` 以下的窄屏断点，没有覆盖 1280、1440、1920 和 2560 等主流桌面宽度。
- 问答卡片使用固定最小高度，未根据视口高度伸缩，导致高分辨率屏幕上可能出现上下留白不协调。

### 适配目标

- 工作区在 1280px 至 3840px 的桌面视口内连续伸缩，页面主体保留 24px 至 64px 的安全边距。
- 2K 和 4K 宽屏优先利用可用空间，但回答正文保持适合阅读的行长；扩展空间主要分配给会话栏、聊天消息区和参考资料区。
- 视口高度较大时，三栏卡片填充剩余空间；会话、消息和参考资料分别独立滚动，不因内容撑高整页。
- 低于桌面推荐宽度时逐级降级，不出现横向滚动；参考资料面板可隐藏，数据源入口继续通过问答区顶部按钮访问。

### 响应式规则

| 视口宽度 | 布局规则 |
| --- | --- |
| `≥ 2560px` | 工作区宽度按视口伸缩，最大不超过 `3440px`；会话栏约 `320px` 至 `360px`，参考资料栏约 `400px` 至 `440px`，聊天正文设置 `1100px` 左右的阅读上限。 |
| `1920px–2559px` | 工作区宽度按视口伸缩，最大不超过 `2240px`；会话栏约 `280px`，参考资料栏约 `360px`，聊天正文设置 `960px` 左右的阅读上限。 |
| `1440px–1919px` | 使用三栏布局；会话栏约 `240px`，参考资料栏约 `320px`，中间问答区优先保留空间。 |
| `1200px–1439px` | 使用紧凑三栏布局；会话栏约 `210px`，参考资料栏约 `280px`，缩小卡片间距和内边距。 |
| `768px–1199px` | 隐藏参考资料栏，保留会话栏和问答区；问答区优先保证问题输入和回答阅读空间。 |
| `< 768px` | 会话列表改为问答区上方的紧凑上下文面板，问答区单列；顶部用户信息允许压缩，输入区和操作区纵向排列。 |

### 实现约束

- 不使用依赖单一分辨率的固定主体宽度；布局优先使用 `minmax()`、`clamp()`、百分比和视口单位。
- 聊天回答内容设置最大阅读宽度，避免 2K、4K 屏幕上单行过长；用户问题气泡可按比例放宽。
- 桌面端卡片高度使用 `calc(100vh - 页面头部与标题区域)`，4K 高视口允许继续增长，并设置合理的最小高度和上限。
- 每次调整问答工作台布局后，至少检查 1280×720、1440×900、1920×1080、2560×1440 和 3840×2160 五种视口；同时检查浏览器缩放 100% 和 125%。

统一交互原型见 `租户访客问答原型.html`。
