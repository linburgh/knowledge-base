# 数值展示控件原型设计

## 设计目标

数值展示控件用于总览卡片、统计摘要、分布列表等紧凑区域，避免位数不确定的数量挤压相邻文字或破坏布局。控件只改变展示结果，不改变实际数值和业务计算。

## 组件属性

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---:|---|
| `value` | `number \| string \| null \| undefined` | — | 实际数值；空值统一显示 `—` |
| `maxDigits` | `number` | `3` | 允许直接显示的最大整数位数，取值范围为 `1` 至 `20` |

## 展示规则

- 实际数值未超过 `10^maxDigits - 1` 时，直接显示实际数值，不启用 Tooltip。
- 实际数值超过上限时，显示由 `maxDigits` 个 `9` 组成的上限文案并追加 `+`。
- `maxDigits=2` 时，`99` 显示为 `99`，`100` 显示为 `99+`。
- `maxDigits=3` 时，`999` 显示为 `999`，`1000` 显示为 `999+`。
- 发生截断时，鼠标悬停或键盘聚焦显示 Tooltip，内容为 `实际数值：<value>`。
- 数值与相邻单位保持同一行；组件继承调用位置的字号、字重、颜色和行高，不自行改变业务层级。
- 当前控件面向非负数量展示；非数字文本、负数和非有限数值保持原文展示，不进行上限缩写。

## 视觉状态

| 实际数值 | 最大位数 | 页面显示 | Tooltip |
|---:|---:|---:|---|
| `8` | `2` | `8` | 无 |
| `99` | `2` | `99` | 无 |
| `100` | `2` | `99+` | `实际数值：100` |
| `8388` | `3` | `999+` | `实际数值：8388` |
| 空值 | `3` | `—` | 无 |

## 复用范围

全站页面和公共组件中的数量型整数统一复用该控件，包括总数、分类数量、样本数量、命中数量、引用数量、成员数量、任务数量、告警数量和证据数量。事件中心、知识库、平台管理、自主评测和自主监控模块使用相同规则。

百分比、成功率、健康率、进度、耗时、容量、文件大小、指标值、阈值、评分、ID、页码、版本号、日期时间、表单配置值和 ECharts 内部数值不使用该控件，继续按各自业务格式精确展示。控件只改变 DOM 展示结果，图表比例、分页、阈值判断、接口参数和详情数据均使用真实数值。
