# 前端原型设计

本目录用于在前端开发前确认知识库问答系统的信息架构、页面关系和核心交互。

文件说明：

- `知识库工作区原型设计.md`：页面结构、交互规则、接口边界和实现约束。
- `知识库工作区原型.html`：平台管理、知识库工作区和开发者中心的统一静态交互原型。
- `平台管理原型设计.md`：平台用户、租户、组织管理的页面结构和交互说明。
- `分页树表交互原型设计.md`：父节点和子节点独立追加加载的分页树表交互规则与接口占位。
- `分页树表交互原型.html`：可点击演示父节点、子节点独立“加载更多”行为的交互原型。
- `组织树快速查找定位原型设计.md`：组织树快速查找、单条直接定位和多条结果选择的交互规则。
- `组织树快速查找定位原型.html`：可点击演示组织树快速查找、结果选择、路径展开和定位高亮。
- `../知识库问答配置/README.md`：知识库工作区“问答”模块配置需求、后端方案、实施方案和右侧滑块交互原型的独立文档目录。
- `知识库系统完整原型设计.md`：平台管理与知识库工作区的统一页面结构和交互规范。
- `租户访客问答原型设计.md`：`tenant_guest` 独立访客问答工作台的页面结构和交互说明。
- `租户访客问答原型.html`：可直接用浏览器打开的访客问答工作台原型。
- `智能体宠物原型设计.md`：智能体宠物的页面结构和交互说明。
- `智能体宠物原型.html`：可直接用浏览器打开的智能体宠物交互原型。
- `../开发者开放API在线文档原型设计.md`：开发者中心在线 API 文档的页面和接口说明，统一原型入口为 `知识库工作区原型.html`。
- `../开发者开放API后端轻量改造方案.md`：基于 Nginx、现有用户 Token 和权限体系的低侵入后端开放 API 方案。
- `../自主评测/README.md`：自主评测相关设计文档的独立目录说明。

本原型的核心约束是：

> 左侧只保留“知识库管理”。文档通过知识库列表操作列进入对应工作区，每个知识库都是独立工作区，文档、索引状态、问答会话、检索结果和引用都必须绑定当前 `kb_id`，不提供跨知识库共享的文档入口。

确认原型后，再按本文档中的页面结构实现 Vue 3 + Element Plus + Bootstrap 基础样式前端。

## 在 WSL Ubuntu 中查看 HTML 原型

在 WSL 终端执行以下命令，使用 Windows 默认浏览器打开原型：

```bash
explorer.exe "$(wslpath -w /home/linburgh/workspace/ai-llm/knowledge-base/docs/前端原型设计/知识库工作区原型.html)"
```

如果当前终端已经位于后端项目根目录，也可以执行：

```bash
explorer.exe "$(wslpath -w "$(pwd)/docs/前端原型设计/知识库工作区原型.html")"
```

其中 `wslpath -w` 会把 WSL Linux 路径转换为 Windows 浏览器可以识别的路径，`explorer.exe` 会调用 Windows 默认浏览器打开该文件。

平台管理、知识库工作区和开发者中心已经整合到 `知识库工作区原型.html`，统一执行上面的命令即可查看。登录后进入“平台管理”，再点击“开发者中心” Tab 查看开放 API 文档。
