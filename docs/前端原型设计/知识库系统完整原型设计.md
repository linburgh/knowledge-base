# 知识库系统完整前端原型设计

## 1. 原型入口

统一 HTML 原型为：

- `知识库工作区原型.html`

该文件已整合平台管理与知识库工作区，左侧导航按权限展示平台管理和知识库管理。

## 2. 页面信息架构

```text
平台管理（仅 p_super_admin）
├── 平台概览
├── 用户管理
├── 租户管理
└── 组织管理

知识库管理
├── 知识库列表
└── 知识库工作区
    ├── 概览
    ├── 文档
    └── 问答
```

平台管理和知识库管理使用同一个应用壳层、左侧菜单和右侧抽屉交互。平台管理员进入租户资源时，顶部应显示当前目标租户。

## 3. 平台管理

### 3.1 平台概览

展示用户总数、正常用户数、租户总数、正常租户数、组织总数和知识库总数，并展示：

- 用户增长趋势。
- 租户资源分布。
- 文档处理状态分布。
- 最近平台活动。

图表支持时间范围切换，点击图表数据可以进入对应管理列表。

### 3.2 用户管理

列表提供用户名/邮箱、状态、所属租户查询条件，并提供查询、重置、分页。操作使用“查看”“修改”等文本按钮。新建和修改通过右侧抽屉完成，字段包含用户名、邮箱、所属租户、所属组织、状态以及平台管理员标识。

### 3.3 租户管理

列表提供租户名称/编码、状态查询条件和分页，展示成员数、知识库数和状态。新建、修改通过右侧抽屉完成，可继续扩展租户管理员与成员管理。

### 3.4 组织管理

采用左侧组织树、右侧组织成员列表结构。成员列表提供成员关键词、状态查询条件和分页；组织新建、修改、负责人和成员调整均使用右侧抽屉。

## 4. 知识库管理与工作区

知识库列表展示名称、描述、状态、创建时间、创建人和操作，不展示模型列。列表提供名称、状态、创建人查询条件与分页，操作列使用“查看”“修改”“删除”文本按钮。

查看知识库进入独立工作区，工作区包含概览、文档和问答三个标签。文档和会话都必须绑定当前 `kb_id`，不提供跨知识库共享入口。

知识库新建和修改使用右侧抽屉，字段包含名称、描述和独立系统提示词。系统提示词为空时使用默认提示词。

知识库概览增加：

- 文档处理趋势。
- 文档状态分布。
- 问答趋势。
- 平均相似度、低相似度问题和无引用回答统计。
- 热门问题、文档引用排行和最近活动。

图表只统计当前知识库 `kb_id` 的数据，不跨知识库混合展示。

## 5. 统一交互和视觉约束

- 所有列表必须具备查询条件和分页。
- 查询、重置、上一页、下一页和页码按钮遵循统一原型样式。
- 列表操作优先使用文本按钮，按钮之间保留明确间距。
- 所有表单使用右侧抽屉，不使用居中弹窗。
- 状态只使用中文文字和文字颜色区分，不使用背景色标签。
- 平台管理、知识库管理和工作区共享同一套字体、颜色、间距、卡片和表格风格。
- 页面主体控制在视口高度内，工作区的会话列表、聊天窗口、引用来源分别独立滚动。
- 平台概览和知识库概览使用统计卡片、柱状趋势图、环形状态图和最近活动列表组合展示。
- 图表无数据时显示空状态，图表数据应来自独立统计接口，不使用当前分页列表数据推算。
- 图表实现统一采用 ECharts，基础布局和字体沿用 Bootstrap 风格，抽屉、选择器等交互沿用 Element Plus。
