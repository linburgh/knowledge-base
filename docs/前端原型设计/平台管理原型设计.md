# 平台管理前端原型设计

> 本文档内容已纳入[知识库系统完整前端原型设计](知识库系统完整原型设计.md)。统一可交互原型请打开 `知识库工作区原型.html`，本文件保留作为平台管理专题说明。

## 1. 页面范围

平台管理只对 `p_super_admin` 展示，包含：

- 平台概览。
- 用户管理。
- 租户管理。
- 组织管理。

普通租户用户不展示平台管理菜单。

## 2. 页面结构

```text
平台管理
├── 平台概览
├── 用户管理
├── 租户管理
└── 组织管理
```

左侧菜单新增“平台管理”，位于知识库管理之前或之后，具体顺序由最终导航方案确认。

## 3. 平台概览

页面展示平台级统计卡片：

- 用户总数。
- 正常用户数。
- 租户总数。
- 正常租户数。
- 组织总数。
- 知识库总数。

下方展示最近创建的租户和最近加入的用户。

概览补充以下图表：

- 用户增长趋势：按日、月展示新增用户和活跃用户。
- 租户资源分布：展示各租户的用户数、组织数和知识库数。
- 文档处理状态：展示已完成、处理中、失败和待处理数量。
- 最近平台活动：展示用户、租户、组织、知识库和文档的近期操作。

图表支持近 7 天、近 30 天、近 90 天和自定义时间范围；点击图表数据可以跳转到对应管理列表。

## 4. 用户管理

### 4.1 列表

页面结构：

```text
用户管理                                      [新建用户]
[用户名/邮箱] [状态] [所属租户] [所属组织] [查询] [重置]
┌──────────────────────────────────────────────────────────┐
│ 用户       邮箱       所属租户       状态       操作       │
│ 张三       ...        企业租户       正常       查看 修改 删除│
│ 李四       ...        产品租户       禁用       查看 修改 删除│
└──────────────────────────────────────────────────────────┘
                         共 28 条  上一页 1 2 下一页
```

查询条件：

- 用户名或邮箱关键词。
- 用户状态。
- 所属租户。
- 所属组织。

操作：

- 查看用户详情。
- 修改用户资料。
- 管理用户所属租户和组织。
- 启用或禁用用户。

用户信息需要体现三类角色：平台角色、租户角色和组织角色。

### 4.2 用户抽屉

点击“新建用户”或“修改”打开右侧抽屉，字段包括：

- 用户名。
- 邮箱。
- 手机号。
- 显示名称。
- 用户状态。
- 所属租户。
- 所属组织。
- 租户角色。
- 平台角色。
- 组织角色。

## 5. 租户管理

### 5.1 列表

```text
租户管理                                      [新建租户]
[租户名称] [状态] [查询] [重置]
┌──────────────────────────────────────────────────────────┐
│ 租户       成员数     知识库数   状态   操作              │
│ 企业租户   36         12         正常   查看 修改 删除    │
└──────────────────────────────────────────────────────────┘
```

操作：

- 查看租户详情。
- 修改租户信息。
- 管理租户成员。
- 管理租户管理员。
- 查看租户组织和知识库统计。

### 5.2 租户抽屉

- 租户名称。
- 租户编码。
- Logo。
- 联系人。
- 联系邮箱。
- 租户状态。
- 租户管理员。

## 6. 组织管理

组织管理采用组织树表结构，主页面只展示组织信息，不直接展示用户列表；组织树表一次性展示全部组织，不分页：

```text
组织管理
┌────────────────┬──────────────────────────────────────────┐
│ 组织树表                                                     │
│ 组织名称｜上级组织｜成员数｜状态｜操作                         │
│ 企业总部｜...  ｜—      ｜54    ｜正常｜成员 / 修改 / 删除      │
│ 企业总部       │ [成员关键词] [状态] [查询] [重置]          │
│ 财务部         │ ┌──────────────────────────────────────┐ │
│ 技术中心       │ │ 成员       角色       状态       操作   │ │
│   平台组       │ └──────────────────────────────────────┘ │
│   算法组       │                                          │
└────────────────┴──────────────────────────────────────────┘
```

组织操作：

- 新建组织。
- 修改组织。
- 调整父子关系。
- 设置负责人。
- 操作列提供“成员”“修改”“删除”。
- 点击“成员”深钻进入当前组织的用户列表。
- 用户列表支持关键词、状态查询和分页，并提供“返回组织树”。
- 将知识库授权给组织。

成员表格提供条件查询和分页，组织树表提供条件查询但不分页，操作按钮使用文本按钮。

## 7. 知识库页面变化

知识库列表仍然保留当前页面结构，但数据来源增加租户和组织上下文：

- 平台超级管理员可以选择目标租户查看知识库。
- 租户管理员默认只查看当前租户知识库。
- 普通用户只查看自己有权限访问的知识库。
- 知识库创建/修改抽屉增加组织归属选择。
- 租户公共知识库的组织字段显示为“租户公共空间”。

## 8. 交互约束

- 所有列表必须提供查询条件和分页。
- 用户、租户、组织树和组织成员列表的“刷新”按钮统一放在查询条件栏中，使用文字按钮；“新建组织”仍与组织工具栏同行。
- 查询和重置按钮使用原型统一样式。
- 所有表单使用右侧抽屉，不使用居中弹窗。
- 列表操作按钮使用文本按钮或统一的更多操作按钮。
- 状态使用文字和颜色区分，不使用状态背景色。
- 平台管理员进入租户资源时，顶部显示当前目标租户名称。

## 9. 待确认页面问题

- 平台管理是否独立使用一套顶部导航。
- 平台超级管理员是否允许直接进入任意租户工作区。
- 租户成员管理和用户管理是否复用同一套成员抽屉。
- 组织授权知识库时是否支持批量选择。
- 用户是否可以同时切换多个租户上下文。
