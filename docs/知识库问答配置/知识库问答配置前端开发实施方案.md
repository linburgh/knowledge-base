# 知识库问答配置前端开发实施方案

## 1. 实施目标

依据《知识库问答配置需求设计文档》和交互原型，在知识库工作区“问答”页面实现唯一的问答配置入口：点击“配置”按钮，从右侧打开配置滑块。配置滑块承载文档处理、检索配置、重排配置、回答策略和高级参数五个 Tab。

当前文档只描述前端开发实施，原型和需求评审通过前不得开始 Vue 页面编码。

## 2. 前端范围

### 2.1 页面和组件

- 知识库工作区“问答”页面。
- 问答页面顶部的配置入口、当前配置版本和状态摘要。
- 右侧配置滑块及遮罩、关闭和滚动交互。
- 五个配置 Tab：文档处理、检索配置、重排配置、回答策略、高级参数。
- 配置状态区、变更摘要、恢复默认、保存草稿和保存并发布操作。
- 文档处理 Tab 的向量模型输入、模型切换影响提示和待重建索引状态。
- 检索测试、Rerank 连接测试和 Prompt 预览区域。

### 2.2 不在前端处理

- 不直接访问数据库、向量库、Ollama、Embedding 或 Rerank 服务。
- 不保存或展示 Token、API Key、密码和服务绝对路径。
- 不在接口失败时使用演示数据或静态配置作为伪造兜底。
- 不在页面内重复定义角色、状态和业务字典。

## 3. 开发前置条件

1. 交互原型评审通过，确认右侧滑块是唯一配置入口。
2. 需求文档中的字段、默认值、状态和权限确认完成。
3. 后端 API Schema、错误结构、权限码和分页/测试返回结构确认完成。
4. 前端公共字典、请求封装、时间格式化和权限指令可复用。

## 4. 页面状态设计

| 状态 | 前端表现 |
|---|---|
| 加载中 | 滑块显示加载状态，禁止提交，不能展示空表单 |
| 未发布 | 显示系统默认配置和“未发布”状态 |
| 草稿 | 显示草稿版本和未发布提示 |
| 已发布 | 显示发布版本、发布时间和发布人 |
| 待重建索引 | 显示受影响文档数量和索引任务状态 |
| 向量模型切换中 | 显示旧模型、目标模型、索引进度，并提示当前问答仍使用旧索引 |
| 向量模型切换失败 | 保留旧模型和旧索引，显示失败原因和重新索引入口 |
| 无权限 | 隐藏编辑操作，按接口返回展示无权限提示 |
| 参数错误 | 在对应字段下显示服务端字段错误 |
| 发布失败 | 保留当前编辑内容和草稿状态，不伪造发布成功 |
| 测试失败 | 在对应测试区域展示错误，不影响正式配置 |

## 5. 前端开发阶段

### 阶段 1：原型和页面结构确认

- 对照 HTML 原型确认工作区 Tab、问答页面和右侧滑块布局。
- 确认滑块宽度、遮罩、关闭、滚动和移动端适配规则。
- 确认五个 Tab 的字段顺序、控件类型、帮助说明和影响提示。

完成标准：页面结构和交互不再出现“问答配置”独立 Tab。

### 阶段 2：问答页面入口开发

- 在知识库工作区问答页面增加配置按钮。
- 展示当前配置状态、版本和索引状态。
- 使用路由或当前工作区状态维护 `kb_id`，不得使用固定知识库数据。
- 实现打开、关闭、遮罩关闭和重复打开时重新加载配置。

完成标准：用户始终从问答页面进入配置滑块，且配置数据绑定当前知识库。

### 阶段 3：配置滑块和表单开发

- 建立配置滑块容器、Tab 导航和统一表单布局。
- 实现文档处理、检索、重排、回答策略和高级参数表单。
- 在文档处理 Tab 增加向量模型文本框，输入平台已发布的模型标识；不允许输入服务地址、密钥或维度，提交时由服务端校验模型有效性。
- 表单标签、字号、控件高度、间距遵守项目公共样式。
- 根据配置字段设置即时禁用逻辑，例如未开启混合检索时禁用关键词权重。
- 对长 Prompt、检索结果和参考资料提供滚动或省略展示。
- 对模型标识、Prompt、测试问题等字段执行统一特殊字符校验；失焦提示字段级错误，保存/发布前阻断提交并保留输入。

完成标准：表单与需求文档字段一一对应，没有业务页面重复字典和样式规则。

### 阶段 4：配置操作和测试交互开发

- 实现恢复默认、保存草稿、变更摘要和保存并发布。
- 实现字段级前端校验，并展示后端返回的校验错误。
- 实现检索测试结果、Rerank 连接状态和 Prompt 预览。
- 测试请求显示加载、超时、失败和重试状态。
- 发布前弹出变更摘要，明确立即生效和需要重新索引的内容。
- 向量模型发布后不能直接显示“已生效”，必须等待索引任务成功并刷新服务端状态。

完成标准：所有操作均调用真实接口，不保留原型演示数据。

### 阶段 5：接口联调和状态完善

- 接入配置查询、草稿、发布、保存并发布、恢复默认、变更摘要和测试接口。
- “保存并发布”只调用 `POST /api/v1/knowledge-bases/{kb_id}/qa-config/save-and-publish`，不得在前端拆分为保存草稿和发布两个请求；失败时由后端事务整体回滚。
- 处理权限错误、版本冲突、索引任务创建失败和网络超时。
- 发布成功后刷新配置版本和问答页面状态。
- 滑块关闭后再次打开，读取服务端最新草稿或已发布配置。

完成标准：页面状态以接口返回为准，失败时不显示错误成功提示。

### 阶段 6：前端质量验证

- 执行 `npm run format:check`。
- 执行 `npm run type-check`。
- 执行 `npm run build`。
- 检查桌面端、窄屏和移动端滑块布局。
- 检查不存在全局样式污染、重复请求和重复提交。

## 6. 前端测试清单

- 从概览、文档切换到问答，问答 Tab 样式和入口正常。
- 点击配置打开右侧滑块，关闭按钮和遮罩关闭正常。
- 五个 Tab 切换时表单内容和未保存状态正确。
- 分块大小、分块重叠、Top-K、候选数量等跨字段校验正确。
- 保存草稿后重新打开仍显示草稿。
- 发布成功后显示新版本，发布失败不覆盖旧状态。
- 无权限用户不能编辑或发布。
- 检索测试、Rerank 测试和 Prompt 预览失败时显示真实错误。
- 配置内容过长时滑块内部滚动，不撑开问答页面。
- 修改向量模型后保存草稿、发布、待重建索引、索引成功和索引失败回退状态正确展示。

## 7. 前端验收标准

1. 问答配置不再作为知识库工作区独立 Tab。
2. 配置滑块视觉和交互与原型一致。
3. 所有列表、测试结果和状态展示使用真实接口数据。
4. 页面不暴露平台级服务凭据。
5. 前端通过格式检查、类型检查和构建检查。
6. 评审遗留问题关闭后，才能进入前端代码合并。
