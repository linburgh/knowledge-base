# 自主监控设计文档

自主监控智能体相关的需求、原型、接口、数据表、告警规则、Agent Harness 和实施文档统一放在本目录下。

当前文档：

- [自主监控需求设计文档.md](自主监控需求设计文档.md)：自主监控智能体的目标、问答/评测智能体与文档处理链路的协同关系、监控域、指标、告警、权限、交互和验收要求。
- [自主监控数据采集方案.md](自主监控数据采集方案.md)：定义业务埋点、通用中间件采集、周期状态采集、事件协议、指标聚合、告警规则和主动探针的落地方案。
- [自主监控数据表设计.md](自主监控数据表设计.md)：定义监控事件、指标、告警、证据、采集配置、通知和审计数据表及其关系。
- [自主监控界面原型设计稿.md](自主监控界面原型设计稿.md)：定义浅色管理后台风格的监控总览、采集总览、指标总览、10 个子模块、统一查询分页、状态表达、告警处理、目标详情追溯和权限交互；数据采集页面只读展示采集结果，不开放采集配置管理。
- [自主监控界面原型设计稿.html](自主监控界面原型设计稿.html)：可直接用浏览器打开的静态交互原型，包含总览状态切换、采集总览、指标总览、目标详情抽屉、模块导航、统一查询栏、列表筛选分页和告警操作演示。
- [../工作备忘.md](../工作备忘.md)：记录自主监控能力的推进状态。

当前阶段先完成自主监控智能体需求和原型评审，评审通过前不得开始其前后端、数据库、Agent 或 Worker 业务编码。
