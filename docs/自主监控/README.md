# 自主监控设计文档

自主监控智能体相关的需求、原型、接口、数据表、告警规则、Agent Harness 和实施文档统一放在本目录下。

当前文档：

- [自主监控需求设计文档.md](自主监控需求设计文档.md)：自主监控智能体的目标、问答/评测智能体与文档处理链路的协同关系、监控域、指标、告警、交互和验收要求。
- [自主监控数据采集方案.md](自主监控数据采集方案.md)：定义业务埋点、通用中间件采集、周期状态采集、事件协议、指标聚合、告警规则和主动探针的落地方案。
- [自主监控数据表设计.md](自主监控数据表设计.md)：定义监控事件、指标、告警、证据、采集配置、通知和审计数据表及其关系。
- [自主监控后端开发实施方案.md](自主监控后端开发实施方案.md)：定义自主监控后端分层、监控 Agent、采集、指标、告警、通知、分析对话复用和开发计划，并标注自主评测底座边界。
- [自主监控前端开发实施方案.md](自主监控前端开发实施方案.md)：定义 `knowledge-base-web` 的页面、组件、图表、权限、查询分页、自动刷新、接口联调和验收方案。
- [自主监控后端联调确实文档.md](自主监控后端联调确实文档.md)：记录前端联调接口、发现的后端能力缺口、补充安排和联调验收状态。
- [自主监控界面原型设计稿.md](自主监控界面原型设计稿.md)：定义浅色管理后台风格的监控总览、采集总览、指标总览、9 个子模块、统一查询分页、状态表达、告警处理和目标详情追溯；数据采集页面只读展示采集结果，不开放采集配置管理。
- [自主监控界面原型设计稿.html](自主监控界面原型设计稿.html)：可直接用浏览器打开的静态交互原型，包含总览状态切换、采集总览、指标总览、目标详情抽屉、模块导航、统一查询栏、列表筛选分页和告警操作演示。
- [../工作备忘.md](../工作备忘.md)：记录自主监控能力的推进状态。

当前已进入自主监控后端开发阶段；需求、原型、数据表设计、统一 DDL、后端实施方案和测试用例保持同步，前端联调仍需以后端接口和自动化测试通过为前置条件。
