# 前端接口缺口

本文档记录前端按原型开发时发现、但后端当前尚未提供或返回字段不足的接口。已存在的接口不重复记录。

## 已具备接口

- `POST /api/v1/auth/login`：登录页面可直接接入。
- `/api/v1/users`：用户基本资料、状态、分页和逻辑删除。
- `/api/v1/tenants`：租户基本资料、状态、分页和逻辑删除。
- `/api/v1/organizations`：组织树、组织 CRUD 和组织成员分页/维护。

## 待补充接口

### 1. 平台概览统计

平台概览统计接口已完成：`GET /api/v1/platform/overview`。接口不能用分页列表推算，当前返回：

- 用户总数、正常用户数。
- 租户总数、正常租户数。
- 组织总数、知识库总数。
- 用户增长趋势。
- 各租户用户数、组织数、知识库数分布。
- 文档处理状态分布。
- 最近平台活动。

支持 `range=7d|30d|90d|custom`；使用 `custom` 时传入 `start_at` 和 `end_at`，时间参数必须包含时区。

### 2. 当前用户和 Token 生命周期

原型需要：

- `GET /api/v1/auth/me`：返回当前用户、平台角色、当前租户、租户角色和组织列表。
- `POST /api/v1/auth/refresh`：刷新登录凭证。
- `POST /api/v1/auth/logout`：使当前凭证失效。

当前前端退出仅清理本地 Token，后端尚无服务端失效接口。

### 3. 平台角色与租户成员关系

用户管理抽屉需要展示和编辑：

- 平台角色。
- 所属租户及租户角色。
- 所属组织及组织角色。

当前已有用户/组织基础接口，但尚缺：

- 平台角色列表和用户授权接口。
- 租户成员列表、新增、修改角色、移除接口。
- 组织成员可选用户列表及批量成员管理接口。

### 4. 租户管理扩展数据

租户列表原型需要展示：

- 成员数。
- 知识库数。
- 租户管理员。
- 组织统计。

当前租户接口只返回租户自身字段，缺少统计和成员/管理员管理接口。

### 5. 知识库租户/组织上下文

平台管理员进入租户资源时需要：

- 按 `tenant_id` 查询知识库。
- 按 `organization_id` 查询知识库。
- 创建/修改知识库时提交租户和组织归属。
- 组织授权知识库及授权列表接口。

当前知识库前端仍使用旧的 owner 查询方式，后端知识库 API 也尚未完整开放这些上下文字段。

### 6. 知识库概览统计

知识库工作区概览页面已按原型实现完整内容，当前统计图表和排行使用页面占位数据。后端补充接口后替换页面数据加载即可。前端图表统一使用 ECharts，通过公共 `TrendLineChart` 组件封装：

- `GET /api/v1/knowledge-bases/{kb_id}/overview`：返回当前知识库的文档总数、分片总数、向量数量和索引失败数。
- 文档处理趋势、文档状态分布和问答趋势（问答次数、活跃会话数双折线图）。
- 平均相似度、低相似度问题、无引用回答统计。
- 热门问题、文档引用排行和最近活动。

接口应支持 `range=7d|30d|90d|custom`，并严格限制在当前 `kb_id` 的数据范围内。
