# 表单特殊字符校验测试用例

## 适用范围

覆盖知识库创建/编辑、问答配置草稿保存与发布、测试问题，以及后端公共文本校验。原型和规则来源：

- [知识库工作区原型](../前端原型设计/知识库工作区原型.html)
- [前端页面原型与实现方案](../前端页面原型与实现方案.md)
- [知识库问答配置需求设计文档](../知识库问答配置/知识库问答配置需求设计文档.md)

## 规则基线

统一表单长度以[全项目表单特殊字符校验设计](../表单特殊字符校验/全项目表单特殊字符校验设计.md)中的“统一表单长度标准”为准。前后端使用同一数值，数据库脚本不做修改。

| 字段类型 | 允许 | 拒绝 |
| --- | --- | --- |
| 知识库名称、模型标识 | 中文、字母、数字、点、下划线、短横线 | 控制字符、零宽/双向字符、路径字符、空格及其他符号 |
| 描述、系统提示词、回答提示词、测试问题 | 正常标点、换行、中文和英文 | 控制字符、零宽/双向字符；超出长度 |
| 上传文件名 | 普通文件名字符 | 路径字符、目录穿越片段、控制及不可见字符 |

## 前端用例

| 编号 | 前置条件 | 测试数据与步骤 | 预期结果 | 状态 |
| --- | --- | --- | --- | --- |
| FE-SC-01 | 打开知识库新建抽屉 | 名称输入 `医疗库/内部`，失焦 | 字段提示不能包含路径字符；保留原输入；保存不可提交 | 待执行 |
| FE-SC-02 | 打开知识库新建抽屉 | 名称输入 `医疗库\u200B`，失焦 | 提示不能包含不可见字符；保存不可提交 | 待执行 |
| FE-SC-03 | 打开知识库新建抽屉 | 描述输入包含括号、引号、换行和 `/` | 校验通过，可继续保存 | 待执行 |
| FE-SC-04 | 打开问答配置抽屉 | 向量模型输入 `model/name` 或带空格值 | 提示模型标识格式错误；不发起保存/发布请求 | 待执行 |
| FE-SC-05 | 打开问答配置抽屉 | 回答提示词输入正常标点、换行 | 校验通过；保存草稿和发布按钮可继续执行 | 待执行 |
| FE-SC-06 | 打开问答配置抽屉 | 测试问题输入零宽字符或超过 1000 字符 | 点击检索测试/Rerank/Prompt 预览时提示错误，不发请求 | 待执行 |
| FE-SC-07 | 任一表单 | 校验失败后修改为合法内容 | 错误状态清除，输入内容未被自动截断或改写 | 待执行 |
| FE-SC-08 | 用户、租户、组织表单 | 分别在账号/编码/名称中输入不可见字符、路径字符和连续点号 | 对应字段失焦提示；提交按钮不发请求 | 待执行 |
| FE-SC-09 | 用户表单 | 密码输入 `P@ssw0rd!`，再输入控制字符 | 普通特殊符号通过，控制字符提示错误 | 待执行 |
| FE-SC-10 | 评测表单 | 评测名称、业务范围、生成要求分别输入特殊字符和换行 | 名称按展示文本规则校验；长文本正常标点和换行通过 | 待执行 |
| FE-SC-11 | 登录页、问答输入框、列表查询 | 输入不可见字符并提交 | 页面提示错误，不发起登录、问答或查询请求 | 待执行 |
| FE-SC-12 | 评测问题导入 | 文件名包含目录路径，或某一问题包含不可见字符 | 选择/解析阶段阻断，提示文件名或问题内容错误 | 待执行 |

## 后端用例

| 编号 | 测试数据与步骤 | 预期结果 | 状态 |
| --- | --- | --- | --- |
| BE-SC-01 | 调用知识库创建/修改接口，名称带 `/`、`..` 或 `\u202E` | 返回业务校验错误；不写入数据库 | 已通过单元测试 |
| BE-SC-02 | 调用问答配置草稿保存/发布，模型标识带空格、`/` 或零宽字符 | 返回业务校验错误；草稿/发布版本不变 | 待执行 |
| BE-SC-03 | 调用问答配置保存，Prompt 含正常标点和换行 | 校验通过，事务正常提交 | 待执行 |
| BE-SC-04 | 调用会话消息接口，正文带控制字符 | 返回业务校验错误；不产生消息记录 | 待执行 |
| BE-SC-05 | 调用文档创建接口，文件名带路径字符或控制字符 | 返回业务校验错误；不创建文档及索引任务 | 待执行 |
| BE-SC-06 | 使用 Unicode 边界字符和最大长度值 | 合法值通过，超长值返回明确字段错误 | 已通过单元测试 |
| BE-SC-07 | 使用 `13800138000`、`+8613800138000`、10 位手机号 | 仅 11 位中国大陆手机号通过，其余返回字段错误 | 已通过单元测试 |
| BE-SC-08 | 使用前端统一长度边界值和超长值 | 前后端在名称、问题、Prompt、密码等字段返回相同长度错误 | 待执行 |
