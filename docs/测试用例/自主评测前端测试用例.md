# 自主评测前端测试用例

## 1. 测试范围

覆盖 `/platform/evaluations` 页面、查询分页、新增任务、问题来源切换、运行状态、评测报告、逐题详情、优化建议、复测、保存草稿、权限、异常状态和真实接口联调。

依据文档：

- [自主评测模块原型设计.md](../自主评测/自主评测模块原型设计.md)
- [自主评测前端开发实施方案.md](../自主评测/自主评测前端开发实施方案.md)
- [知识库问答评测Agent需求与实施方案.md](../自主评测/知识库问答评测Agent需求与实施方案.md)

## 2. 测试环境和约定

- 使用真实 API Mock 或联调环境，不保留前端静态 `tasks`、固定指标和 `setTimeout` 模拟数据。
- 测试角色包含平台超级管理员和无权限角色。
- 覆盖桌面端和移动端抽屉布局。
- 覆盖 `pending`、`running`、`completed`、`failed`、`cancelled` 和 `indeterminate`。
- 时间统一验证 `YYYY年MM月DD日 HH:mm:ss`，列表长文本验证单行省略和 Tooltip。

## 3. 测试用例字段

| 字段 | 说明 |
|---|---|
| 用例编号 | 唯一编号，如 `FE-EVAL-001` |
| 用例名称 | 可验证的页面或交互行为 |
| 优先级 | P0、P1、P2 |
| 前置条件 | 用户、路由、接口返回和页面状态 |
| 操作步骤 | 用户操作和请求变化 |
| 预期结果 | 页面展示、按钮状态和接口行为 |
| 状态 | 未执行、通过、失败、阻塞 |

## 6. 执行、轮询和状态

| 编号 | 用例 | 优先级 | 操作步骤 | 预期结果 |
|---|---|---:|---|---|
| FE-EVAL-024 | 创建运行 | P0 | 点击执行并确认 | 调用创建运行接口，立即得到 `run_id`，不等待模型执行 |
| FE-EVAL-025 | pending 状态 | P0 | 运行返回 `pending` | 展示等待状态，按规则开始轮询 |
| FE-EVAL-026 | running 状态 | P0 | 后端返回已完成数和总数 | 展示执行中进度，禁用执行和删除 |

| FE-EVAL-029 | cancelled 状态 | P1 | 后端返回 cancelled | 展示取消原因和重新执行入口 |
| FE-EVAL-030 | 轮询请求失败 | P0 | 连续轮询接口失败 | 展示错误和重新加载，不能伪造进度 |

## 10. 前端验收

- [ ] 超级管理员完成“新增 → 执行 → 查看报告 → 查看逐题 → 帮我优化 → 复测 → 保存草稿 → 删除”。
- [ ] 导入和 Agent 生成两种任务配置均可正确提交。
- [ ] 列表查询、分页、状态和结论与后端数据一致。
- [ ] 运行中轮询、按钮限制、离开页面清理和重新进入恢复正确。
- [ ] 报告使用真实统计数据，高级指标无法评估时正确展示。
- [ ] 接口失败、空数据、无权限和错误状态完整。
- [ ] 不存在固定演示数据、静态统计值或失败兜底数据。
- [ ] `format:check`、`type-check` 和 `build` 全部通过。
