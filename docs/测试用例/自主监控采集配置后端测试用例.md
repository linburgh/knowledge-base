## 验收标准

- 配置脚本、装饰器编码、代码入口和事件名称完全一致。
- 配置不包含凭证、本机绝对路径、完整业务文本或任意可执行表达式。
- 数据库是采集配置唯一事实源，页面不开放配置修改操作。
- 无数据、失败、部分、过期和不可用状态能够独立表达。
- 所有监控写入失败均不得反向阻断业务主流程。
