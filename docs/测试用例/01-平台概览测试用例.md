# 平台概览测试用例

## 1. 测试范围

验证平台超级管理员进入平台概览后的统计卡片、趋势图、状态分布、资源分布和最近活动展示，以及统计接口的权限和数据准确性。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 页面进入 | 使用平台超级管理员打开平台概览 | 页面正常加载，统计卡片和图表区域展示完整 |
| 前端-002 | 统计卡片 | 检查用户、租户、组织、知识库数量 | 数值来自统计接口，不显示静态占位数据 |
| 前端-003 | 趋势图 | 切换窗口宽度并查看趋势图 | 图表自适应，不溢出、不重叠，图例含义正确 |
| 前端-004 | 空数据 | 后端返回空统计结果 | 页面显示明确空状态，不显示错误的 0 以外的伪造数据 |
| 前端-005 | 加载状态 | 模拟统计接口延迟 | 页面显示加载状态，完成后替换为真实数据 |
| 前端-006 | 接口失败 | 模拟统计接口 500 | 页面展示错误提示，不能用静态数据兜底 |
| 前端-007 | 越权访问 | 使用无平台概览菜单权限账号访问页面 | 跳转无权限页面或不展示菜单入口 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 正常查询 | 平台管理员请求平台统计接口 | 返回用户、租户、组织、知识库及趋势统计 |
| 后端-002 | 权限校验 | 普通租户用户请求平台统计接口 | 返回 403，不泄露平台范围数据 |
| 后端-003 | 数据范围 | 修改单个租户数据后重新查询 | 统计结果与数据库实际数据一致 |
| 后端-004 | 时间范围 | 查询趋势数据边界日期 | 日期范围、时区和聚合粒度正确 |
| 后端-005 | 服务异常 | 统计依赖服务不可用 | 返回统一错误结构并记录错误日志 |

## 4. 验收重点

- 图表数据必须来自统计接口，不能由当前分页列表推算。
- 平台统计不能被租户或组织角色访问。
