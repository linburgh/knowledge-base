# 知识库概览测试用例

## 1. 测试范围

验证当前知识库的文档统计、索引状态、趋势图、问答趋势、配置摘要和文档引用排行。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 页面进入 | 从知识库列表进入概览 | 当前 kb_id 和知识库名称正确 |
| 前端-002 | 统计展示 | 检查文档总数、索引完成、处理中、失败 | 数值来自统计接口且状态含义正确 |
| 前端-003 | 图表适配 | 缩放窗口和滚动页面 | 图表不变形、不遮挡其他内容 |
| 前端-004 | 无文档 | 当前知识库没有文档 | 显示空状态和合理引导，不显示错误统计 |
| 前端-005 | 接口加载 | 模拟统计接口延迟或失败 | 展示加载或错误状态，不使用静态数据兜底 |
| 前端-006 | 菜单权限 | 无概览权限访问路由 | 跳转无权限页面或阻止进入 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 概览查询 | 查询当前知识库统计 | 返回当前知识库真实统计 |
| 后端-002 | 跨知识库 | 修改请求 kb_id 为其他知识库 | 返回 403 或无数据 |
| 后端-003 | 统计一致性 | 与文档、索引、问答明细比对 | 总数和状态数量一致 |
| 后端-004 | 时间聚合 | 查询趋势数据 | 日期、时区和聚合结果正确 |
| 后端-005 | 依赖异常 | 统计依赖服务失败 | 返回统一异常并记录日志 |

## 4. 重点验收

- 前端不根据分页列表推算全量统计。
- 所有统计都必须绑定当前知识库和授权范围。
