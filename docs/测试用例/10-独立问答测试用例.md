# 独立问答测试用例

## 1. 测试范围

验证访客或独立问答用户的入口、知识库选择、问题发送、会话列表、回答引用和租户边界；单个问题长度上限为 500 个字符。

## 2. 前端交互测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 入口访问 | 使用独立问答角色登录 | 只展示独立问答入口，不展示不应可见的平台菜单 |
| 前端-002 | 知识库选择 | 打开知识库选择器 | 只展示已授权且可用知识库 |
| 前端-003 | 空知识库 | 当前账号没有可访问知识库 | 显示明确引导，不进入错误问答状态 |
| 前端-004 | 问题校验 | 空问题、超长问题提交 | 显示校验提示，不发起请求 |
| 前端-005 | 问答交互 | 输入问题并发送 | 显示用户消息、回答加载状态和最终回答 |
| 前端-006 | 引用展示 | 回答包含参考资料 | 展示来源、片段和引用数量，长内容可滚动 |
| 前端-007 | 失败重试 | 模拟网络失败或服务超时 | 保留输入，提示失败，允许重新提交 |
| 前端-008 | 租户切换 | 切换租户上下文 | 知识库列表、当前会话和回答状态重新加载，不串数据 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 可访问知识库 | 查询独立问答知识库列表 | 只返回当前用户授权范围内知识库 |
| 后端-002 | 访客问答 | 提交合法问题 | 按访客权限检索并返回答案及引用 |
| 后端-003 | 未授权知识库 | 伪造 kb_id 发问 | 返回 403，不检索目标知识库 |
| 后端-004 | 会话边界 | 查询或继续其他用户会话 | 返回 403 或 404 |
| 后端-005 | 输入校验 | 缺少问题、kb_id 或超长问题 | 返回 422 或统一业务错误 |
| 后端-006 | 敏感异常 | 模型服务不可用 | 返回友好错误或降级结果，日志不包含 Token、密码和 API Key |
| 后端-007 | 租户隔离 | 切换租户后使用旧租户资源 ID | 拒绝访问，不能跨租户读取或写入 |

## 4. 重点验收

- 独立问答不应反向暴露知识库管理、平台管理和文档管理菜单。
- 访客问答必须同时校验用户、租户、知识库授权和会话归属。
