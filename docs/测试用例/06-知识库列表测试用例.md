# 知识库列表测试用例

## 1. 测试范围

验证知识库列表查询、分页、新增、修改、授权、删除和进入工作区。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 列表加载 | 打开知识库管理 | 查询条件、列表字段、操作按钮和分页正常展示 |
| 前端-002 | 条件查询 | 输入知识名称、状态、创建用户查询 | 请求条件正确，列表从第一页展示 |
| 前端-003 | 重置查询 | 点击重置 | 条件清空并恢复默认列表 |
| 前端-004 | 新增校验 | 不填名称、租户等必填字段提交 | 显示字段级必填提示，不发起保存请求 |
| 前端-005 | 新增成功 | 填写名称、租户、描述、系统提示词 | 保存成功并进入或刷新列表 |
| 前端-006 | 修改知识库 | 打开修改抽屉并保存 | 表单回填正确，列表更新 |
| 前端-007 | 授权交互 | 切换用户授权、组织授权，查询待选项，多选确认 | 临时选择、确认回填、取消丢弃符合设计 |
| 前端-008 | 删除确认 | 点击删除后确认或取消 | 确认删除，取消不改变列表 |
| 前端-009 | 进入工作区 | 点击工作区 | 路由携带正确 kb_id，显示当前知识库 |
| 前端-010 | 越权展示 | 使用无授权账号登录 | 不展示未授权知识库 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 分页查询 | 传入名称、状态、创建人和分页参数 | 返回正确总数和分页数据 |
| 后端-002 | 创建知识库 | 提交合法数据 | 创建成功，租户边界正确 |
| 后端-003 | 必填校验 | 缺少名称或租户 | 返回校验错误，不写入数据 |
| 后端-004 | 授权保存 | 保存组织或用户授权 | 授权关系正确，重复授权不重复插入 |
| 后端-005 | 授权边界 | 提交其他租户组织或用户 | 返回 403 或 404 |
| 后端-006 | 删除知识库 | 删除含文档、会话、索引的知识库 | 按业务规则处理依赖，事务完整 |
| 后端-007 | 系统提示词 | 保存超长或非法提示词 | 返回校验错误，不覆盖旧版本 |

## 4. 重点验收

- 知识库只归属租户，组织访问通过授权关系控制。
- 列表所有操作必须绑定当前用户可访问范围。
