# 自主监控智能体协同测试用例

## 1. 测试范围

验证自主监控智能体与知识库问答智能体、自主评测智能体之间的结构化遥测、受控探针、环境快照、结果可信度判断、权限隔离和循环调用防护。

## 2. 功能测试用例

| 编号 | 场景 | 前置条件 | 操作步骤 | 预期结果 | 验收状态 |
| --- | --- | --- | --- | --- | --- |
| MON-AGENT-001 | 问答运行遥测 | 问答智能体可执行 | 执行一次正常问答并查询监控事件 | 记录请求开始、检索、模型调用和完成事件，包含脱敏的运行 ID、耗时、命中数和引用数 | 待执行 |
| MON-AGENT-002 | 问答失败分类 | 模拟检索失败、模型超时和权限拒绝 | 分别执行问答并查看监控数据 | 失败原因分别结构化记录，不把不同失败合并成笼统“系统异常” | 待执行 |
| MON-AGENT-003 | 监控问答探针 | 已配置专用监控租户、知识库和固定问题 | 触发一次监控探针 | 探针使用 `purpose=monitor_probe`，只读执行，不创建普通会话，不污染业务问答统计 | 待执行 |
| MON-AGENT-004 | 探针失败边界 | 使专用探针知识库或问答链路失败 | 执行探针并观察业务状态 | 只标记探针范围异常，不直接判定全部租户问答不可用 | 待执行 |
| MON-AGENT-005 | 探针预算 | 配置探针超时、频率和并发限制 | 连续触发超过预算的探针 | 超出预算的调用被拒绝或延迟，不影响正常问答请求 | 待执行 |
| MON-AGENT-006 | 评测执行证据 | 创建一个评测任务 | 执行完整评测并查询监控事件时间线 | 能看到领取、运行、问题执行、指标计算、报告生成和持久化等阶段事件 | 待执行 |
| MON-AGENT-007 | 评测质量失败 | 评测执行完整但质量门禁不通过 | 查看评测结果和监控告警 | 评测标记 `quality_failed`，监控标记质量问题，不误报为 Worker 或基础设施故障 | 待执行 |
| MON-AGENT-008 | 评测环境异常 | 评测期间注入模型超时、向量库失败或 Worker 心跳过期 | 完成或中断评测并查看结果 | 评测与监控分别记录质量结果和环境异常，必要时标记 `environment_degraded` 或 `execution_failed` | 待执行 |
| MON-AGENT-009 | 评测结果不可判定 | 仅完成部分题目或有效样本不足 | 查询评测报告 | 结果标记 `inconclusive`，监控不得将其直接视为质量通过或质量失败 | 待执行 |
| MON-AGENT-010 | 评测环境快照 | 监控可提供环境快照 | 启动评测并在监控接口不可用时再次启动评测 | 正常时记录快照；监控不可用时评测仍可执行，并标记快照缺失 | 待执行 |
| MON-AGENT-011 | 评测作为质量探针 | 问答接口返回成功但引用率持续下降 | 完成一轮评测并观察监控 | 监控可关联评测质量结果生成告警，但不修改评测结论或自动调整配置 | 待执行 |
| MON-AGENT-012 | 告警关联 | 模拟索引失败、问答引用率下降和评测门禁不通过 | 查询事件关联结果 | 三类事件可合并到同一故障上下文，能够展示证据链和影响范围 | 待执行 |

## 3. 安全与边界测试用例

| 编号 | 场景 | 操作步骤 | 预期结果 | 验收状态 |
| --- | --- | --- | --- | --- |
| MON-AGENT-013 | 敏感内容脱敏 | 查询问答遥测和评测事件 | 默认不展示完整问题、答案、文档片段、Token 或 API Key；需要查看时按权限加载 | 待执行 |
| MON-AGENT-014 | 租户隔离 | 使用租户管理员查询监控和评测详情 | 只能查看当前租户范围，不能通过 ID、Trace ID 或探针参数越权 | 待执行 |
| MON-AGENT-015 | 禁止自动重跑 | 模拟评测失败并触发监控告警 | 观察任务状态和调用记录 | 监控只生成告警和建议，不自动创建、重试、暂停或终止评测 | 待执行 |
| MON-AGENT-016 | 禁止循环调用 | 模拟监控异常、评测异常和问答异常同时发生 | 查看 Agent 调用链 | 不出现“评测等待监控、监控等待评测”的同步循环，不发生无限重试 | 待执行 |
| MON-AGENT-017 | 私有边界 | 检查跨 Agent 导入和工具注册 | 验证监控只能调用公开结构化协议 | 不导入问答或评测 Agent 的私有 Prompt、函数、模型实例、Runtime 或内部状态 | 待执行 |

## 4. 验收标准

- 问答智能体和自主评测智能体均能向监控提供可追踪的结构化运行事实。
- 监控探针与真实业务问答、评测任务和租户用量严格隔离。
- 评测质量结论、评测执行状态和基础设施健康状态分别表达，不相互覆盖。
- 监控异常不会自动修改、重试或终止问答、评测和知识库业务数据。
- 监控不可用时，问答和评测仍可按各自协议独立运行。
- 所有跨 Agent 调用均经过公开协议、权限校验、数据范围校验和资源预算校验。
