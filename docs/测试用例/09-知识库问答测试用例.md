# 知识库问答测试用例

## 1. 测试范围

验证知识库问答页面的会话列表、快速查找、会话切换、重命名、删除、新建会话、问题发送、流式或等待状态、回答、引用、降级和问答配置入口。

## 4. 配置修改后的实际影响测试

本节不只验证“配置能否保存”，还要验证配置发布后是否改变了对应的问答、检索、索引和运行行为。每条用例执行前应固定同一知识库、同一测试问题、同一测试文档和同一账号，先记录基线结果，再修改一个配置并重新发布，最后对比修改前后的结果。

### 4.1 配置影响验证矩阵

| 配置类别 | 修改示例 | 需要观察的实际影响 | 合格判定 |
|---|---|---|---|
| 文档处理 | 分块大小 600 改为 300 | 新索引的分块数量、分块边界、引用片段和召回结果变化 | 新索引使用新参数，旧索引仍可用，引用来自正确分块 |
| 文档处理 | 分块重叠 100 改为 0 | 相邻分块上下文重复程度和跨段问题召回情况 | 新索引分块重叠符合配置，不影响旧会话 |
| 文档处理 | 向量模型切换 | 修改 `document.embedding_model` 并发布 | 创建新索引代次，索引成功后查询向量和文档向量使用同一模型 |
| 文档处理 | 标题保留、表格处理、重复内容处理 | 分块内容是否保留标题、表格关系和重复标记 | 文档重新处理后内容与配置一致 |
| 检索配置 | Top-K 5 改为 10 | 检索测试返回候选数量和问答参考资料数量 | 返回数量受配置控制，不超过系统上限 |
| 检索配置 | 向量检索改为关键词检索 | 产品名、编号、专有名词的命中结果和排序 | 关键词命中结果真实出现，不能仍使用旧检索方式 |
| 检索配置 | 向量检索改为混合检索 | 语义问题和精确术语问题的召回差异 | 向量和关键词结果按权重合并，排序可解释 |
| 检索配置 | 相似度阈值提高 | 低相关结果、空结果处理和回答中的引用数量 | 低于阈值结果被过滤，空结果策略按配置执行 |
| 检索配置 | 查询改写开启 | 追问或指代问题的检索词、候选结果和最终答案 | 只对新问答生效，查询改写失败有明确降级行为 |
| 重排配置 | 关闭重排 | 引用顺序、最终资料相关性和耗时 | 不调用重排服务，结果使用检索排序 |
| 重排配置 | 开启重排并修改候选数量 | 重排前候选数、重排后顺序、最终返回数量 | 候选数和返回数分别符合配置，排序发生可验证变化 |
| 重排配置 | Rerank 服务不可用 | 向量结果回退或问答终止 | 严格按失败策略执行，不伪造重排成功 |
| 回答策略 | 回答风格改为客户讲解 | 语言语气、表达方式、结构和专业程度 | 新回答符合目标风格，不改变检索事实 |
| 回答策略 | 最大回答长度改变 | 答案长度和是否截断 | 新回答受长度约束，不能截断到半句或丢失必要引用 |
| 回答策略 | 必须引用资料开关 | 答案引用标记、右侧参考资料和无资料回答 | 开启时答案必须有有效引用，关闭时按配置允许无引用回答 |
| 回答策略 | 资料不足处理改变 | 无命中问题的回答内容 | 明确说明资料不足、拒答或资料摘要行为与配置一致 |
| 回答策略 | Prompt 修改 | 术语、回答规则、禁答规则和格式 | 新问答使用新 Prompt，不能覆盖系统安全约束 |
| 高级参数 | 最大执行步骤、工具调用次数改变 | Agent 工具调用次数、结束原因和回答完整性 | 达到限制时按预期结束，不出现无限循环 |
| 高级参数 | Agent 或工具超时改变 | 超时等待时间、重试次数和降级回答 | 按配置超时，日志记录实际阶段，降级策略正确执行 |
| 高级参数 | Graph recursion limit 改变 | LangGraph 最大递归次数和停止行为 | 达到限制时可控结束，不向客户展示堆栈 |

### 4.2 配置实际生效测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 影响-001 | 基线记录 | 使用固定问题执行问答，记录检索结果、引用、答案、耗时和版本号 | 形成修改前基线，包含 `qa_config_version_id` 和 `index_version_id` |
| 影响-002 | 仅修改即时参数 | 只修改 Top-K、阈值、Rerank 或回答策略并发布 | 新问答读取新配置，文档索引不被无故重建 |
| 影响-003 | 仅修改索引参数 | 只修改分块大小、重叠或清洗参数并发布 | 创建新索引任务，旧索引在新索引完成前继续可用 |
| 影响-004 | 索引切换前问答 | 新索引构建期间发起新问答 | 按系统定义使用旧 active 索引，不读取未完成索引 |
| 影响-005 | 索引切换后问答 | 新索引构建成功并切换 active 后发起新问答 | 新问答使用新索引和对应配置版本 |
| 影响-006 | 旧会话继续追问 | 发布新配置并切换索引后，在旧会话中继续提问 | 按会话冻结的配置版本和索引版本处理，回答可追溯 |
| 影响-007 | 新旧会话对比 | 同一问题分别在旧会话和新会话中执行 | 新会话使用新版本，旧会话不因发布被静默改写 |
| 影响-008 | 发布失败 | 模拟发布成功但索引任务创建失败 | 旧发布版本和旧 active 索引保持不变，客户问答不中断 |
| 影响-009 | 重排影响 | 固定向量候选集，分别关闭和开启重排 | 能观察到重排调用状态、排序或失败回退差异 |
| 影响-010 | Prompt 影响 | 只修改 Prompt 中的回答规则，使用相同检索资料提问 | 答案表达按新规则变化，事实和引用仍来自资料 |
| 影响-011 | 降级影响 | 关闭或开启降级回答，模拟 Agent 或模型超时 | 分别返回配置要求的错误提示、资料摘要或降级答案 |
| 影响-012 | 配置回滚 | 发布新配置后恢复默认并再次发布 | 新问答恢复默认行为，旧会话版本仍可追溯 |
| 影响-013 | 配置隔离 | 对知识库 A 修改配置后访问知识库 B | B 的配置、索引、检索和回答行为不发生变化 |
| 影响-014 | 版本追溯 | 查询问答消息、引用和会话详情 | 能定位使用的配置版本、索引版本、检索模式和重排状态 |

### 4.3 影响测试数据要求

- 至少准备一份包含标题、表格、重复段落和跨段上下文的测试文档。
- 至少准备精确术语问题、语义问题、追问、无资料问题和需要多分块综合的问题。
