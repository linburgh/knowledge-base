## 5. 测试过程中修复的问题

1. 管理类 API 缺少路由级认证依赖，未认证请求曾可访问用户、租户和平台统计接口；已补充认证和平台超级管理员依赖，并通过未认证/访客边界测试。
2. 知识库创建未写入数据库必填的数字 `created_by`；已根据 `owner_id` 解析数据库用户并写入数字用户 ID。
3. Worker 读取任务内嵌问题内容时错误优先读取不存在的文件；已改为优先使用保存的问题内容，并兼容完整文件名后缀。
4. 知识库修改审计字段使用模块内异步 `list` 函数，产生未等待协程告警；已改为 `list(values.keys())`。
5. 知识库可授权用户和组织成员候选接口曾直接返回 `password_hash`；已改为显式选择安全字段，并通过真实接口校验响应不包含敏感字段。
6. 组织成员候选分页在 DDL 不建立外键的约束下使用隐式 JOIN，导致 HTTP 500；已补充显式 JOIN 条件并通过分页、添加、修改、删除联调。
7. 租户删除未检查活动成员、组织和知识库，可能留下活动知识库孤儿数据；已改为存在活动依赖时返回 HTTP 409，并通过临时租户探针验证删除前后数据一致性。
8. Rerank 请求在候选分块不足最终返回数时传递过大的 `top_n`，导致适配器 HTTP 400 和 fail-open；已将 `top_n` 限制为候选分块数量。
9. 文档上传未拒绝空文件；已增加空文件校验并验证拒绝上传不产生文档记录。
10. 用户服务未校验邮箱格式；已增加邮箱格式校验并通过非法邮箱边界测试。
11. 访客问答请求失败时输入内容会被清空；已恢复失败前输入，浏览器用例验证可重试。
12. 文档上传后使用临时 `asyncio.create_task`，服务停止会留下永久 `running/processing`；已改为启动时运行的索引 Worker，增加失联恢复、任务总超时、Embedding 受控并发和重试。
13. 租户详情统计未返回组织数量，导致组合依赖状态不可见；已补充组织统计并通过成员/组织/知识库组合删除约束验证。
14. 停用租户仍会出现在成员租户列表，且显式失效租户 ID 会错误回退到其他租户上下文；已过滤停用租户并禁止显式租户上下文回退，通过停用后的切换和资源访问验证。
15. 关键词检索评分表达式使用 PostgreSQL 无法推断类型的绑定参数，导致检索测试 HTTP 500；已改为显式整数类型表达式并通过检索测试。
16. 知识库删除未检查活动文档和会话依赖，可能留下孤儿数据；已增加事务内依赖检查，存在依赖返回 HTTP 409。
