# 文档管理测试用例

## 1. 测试范围

验证文档查询、分页、上传、文件校验、索引状态、查看分片、重新索引、删除和知识库边界。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 列表加载 | 打开文档管理 | 文档名称、类型、大小、状态、操作和分页正常展示 |
| 前端-002 | 条件查询 | 输入文档名称和状态查询 | 结果与条件一致，页码回到第一页 |
| 前端-003 | 上传必填 | 不选择文件提交 | 显示文件必填提示，不上传 |
| 前端-004 | 文件校验 | 上传空文件、超限文件、不支持类型 | 显示明确错误，阻止上传 |
| 前端-005 | 上传成功 | 上传合法文件 | 显示处理中状态并刷新列表 |
| 前端-006 | 状态轮询 | 文档从处理中变为完成或失败 | 状态正确更新，失败显示重试入口 |
| 前端-007 | 查看分片 | 点击查看 | 打开分片详情抽屉，支持内容查询和分页 |
| 前端-008 | 重新索引 | 对失败文档点击重新索引 | 状态回到处理中，按钮状态正确 |
| 前端-009 | 删除确认 | 删除文档并确认或取消 | 确认删除，取消不产生请求 |
| 前端-010 | 长内容和滚动 | 使用长文档名、长分片内容 | 单行省略，详情区域可滚动，不撑开页面 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 文档分页 | 传入 kb_id、名称、状态、分页参数 | 返回当前知识库分页数据 |
| 后端-002 | 文件安全 | 上传非法扩展名、空文件、超大文件 | 拒绝上传并返回统一错误 |
| 后端-003 | 文档创建 | 上传合法文件 | 保存文档元数据并创建索引任务 |

## 索引任务可靠性补充

| 用例 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-003A | Worker 异步接管 | 上传文档后不依赖 HTTP 请求协程，查询任务状态 | 文档进入 `pending`，由索引 Worker 执行并最终进入 `ready` 或 `failed` |
| 后端-003B | Worker 重启恢复 | 索引执行期间停止服务并重新启动 | 超过失联阈值的 `running` 任务重新进入 `pending`，不会永久停留在 `processing` |
| 后端-003C | Embedding 受控并发 | 上传包含大量分块的文档 | Embedding 按配置批量处理并限制并发，任务更新时间持续刷新 |
| 后端-003D | 索引超时收尾 | 模拟 Embedding 持续超时 | 任务和文档进入 `failed`，记录超时原因，不保留 `running/processing` 僵尸状态 |

## 4. 重点验收

- 文档状态为 ready 后才允许稳定进入问答。
- 文档、分片、索引任务必须绑定当前知识库。

## 5. 2026-07-26 自动化执行补充

已执行非法扩展名、空文件、拒绝上传无副作用、分片查询和不存在文档边界；空文件现在返回 HTTP 400。超大文件、失败重试和删除事务故障仍未判定为通过。
