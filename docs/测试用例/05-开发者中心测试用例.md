# 开发者中心测试用例

## 1. 测试范围

验证开放 API 文档导航、接口搜索、参数展示、响应示例、代码示例切换和权限说明。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 页面加载 | 打开开发者中心 | 左侧接口导航和右侧详情正常展示 |
| 前端-002 | 接口切换 | 点击知识库、检索、问答、会话等接口 | 标题、路径、参数和响应示例同步切换 |
| 前端-003 | 搜索接口 | 输入接口名称、路径或参数关键词 | 展示匹配接口，无结果时显示空状态 |
| 前端-004 | 代码切换 | 在 cURL、Python、JavaScript 之间切换 | 代码内容和语言标签正确切换 |
| 前端-005 | 长内容 | 查看长响应和代码示例 | 代码区域可滚动，不撑开页面 |
| 前端-006 | 权限提示 | 查看需要申请权限的接口 | 状态、权限范围和错误说明清晰 |
| 前端-007 | 加载失败 | 模拟文档数据接口失败 | 展示错误状态，不显示伪造接口结果 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | Token 认证 | 使用合法 Token 调用开放问答接口 | 返回授权范围内结果 |
| 后端-002 | 无 Token | 不携带 Token 调用 | 返回 401 |
| 后端-003 | 资源权限 | 使用无知识库权限 Token 调用 | 返回 403，不泄露文档内容 |
| 后端-004 | 参数校验 | 缺少必填参数或传入非法类型 | 返回 422 |
| 后端-005 | 限流 | 超过调用频率 | 返回 429，并返回统一错误结构 |
| 后端-006 | 异常追踪 | 模型或检索服务异常 | 返回 request_id，服务日志包含错误上下文 |

## 4. 重点验收

- 文档中的接口路径、参数、响应示例必须与真实接口一致。
- 开发者中心不得展示用户、租户、组织等未开放接口。
