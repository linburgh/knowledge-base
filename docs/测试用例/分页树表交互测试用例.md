# 分页树表交互测试用例

## 1. 测试范围

验证父节点追加分页、子节点独立追加分页、展开状态保持、局部加载状态、异常重试和空数据交互。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 首次加载 | 打开分页树表 | 首批父节点展示，底部显示父节点“加载更多”，不显示传统页码 |
| 前端-002 | 展开父节点 | 点击父节点展开图标 | 仅当前父节点加载并展示首批子节点，其他父节点不受影响 |
| 前端-003 | 子节点追加 | 点击当前父节点内部“加载更多” | 仅追加当前父节点子节点，其他父节点数据、展开状态保持不变 |
| 前端-004 | 父节点追加 | 点击表格底部“加载更多” | 追加下一批父节点，已展开父节点和子节点不重置 |
| 前端-005 | 独立加载状态 | 同时观察父节点和子节点加载 | 加载提示只出现在对应位置，其他区域可见数据保持不变 |
| 前端-006 | 子节点失败 | 模拟当前父节点子节点接口失败 | 已加载子节点保留，当前父节点内部显示错误和“重新加载” |
| 前端-007 | 父节点失败 | 模拟父节点接口失败 | 已加载父节点保留，表格底部显示错误和“重新加载” |
| 前端-008 | 无更多数据 | 返回 `has_more=false` | 对应层级隐藏“加载更多”，父节点和子节点均不显示页码 |
| 前端-009 | 空子节点 | 展开没有子节点的父节点 | 当前父节点内部显示“暂无子节点”，不显示子节点加载按钮 |
| 前端-010 | 查询重置 | 输入查询条件后查询、重置 | 树表从第一批父节点重新加载，旧父子节点状态不混入新结果 |
| 前端-011 | 多级展开 | 连续展开有 10 级以上的测试树 | 每一级节点均显示并可继续展开，每一级独立请求直接子节点 |

## 3. 接口配合测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 接口-001 | 父节点批次 | 请求父节点接口并传入游标 | 返回 `items`、`next_cursor`、`has_more`，排序稳定 |
| 接口-002 | 子节点批次 | 请求指定父节点的子节点接口 | 只返回当前父节点子节点，不返回其他父节点数据 |
| 接口-003 | 游标连续性 | 连续请求父节点和子节点“加载更多” | 不重复、不遗漏、不回到第一页 |
| 接口-004 | 权限范围 | 使用无权父节点或子节点 ID 请求 | 返回统一无权限或资源不存在响应，不泄露数据 |
| 接口-005 | 数据变化 | 加载过程中新增或删除节点 | 使用稳定排序和游标，前端不重复追加已展示节点 |

## 4. 评审验收

- 不出现传统页码、上一页和下一页控件。
- 父节点和子节点的“加载更多”互相独立。
- 任何局部加载失败都不能清空已加载树表数据。
