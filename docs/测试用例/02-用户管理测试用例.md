# 用户管理测试用例

## 1. 测试范围

验证用户查询、分页、新增、修改、查看、状态控制、租户和组织归属，以及平台管理员权限控制。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 列表加载 | 打开用户管理 | 查询条件、列表、操作列和分页正常展示 |
| 前端-002 | 条件查询 | 输入用户名称、邮箱、状态、租户后查询 | 请求携带全部条件并从第一页展示结果 |
| 前端-003 | 重置条件 | 设置条件后点击重置 | 条件清空，列表回到第一页 |
| 前端-004 | 分页 | 切换页码、每页条数 | 请求参数正确，列表数据和页码同步 |
| 前端-005 | 新增校验 | 不填写必填字段提交 | 字段下方显示必填提示，不提交接口 |
| 前端-006 | 新增成功 | 填写合法用户信息保存 | 提示成功，关闭表单并刷新列表 |
| 前端-007 | 修改用户 | 修改邮箱、状态、租户或组织 | 表单回填正确，保存后列表展示最新值 |
| 前端-008 | 操作菜单 | 点击查看、修改等文本操作 | 打开对应详情或编辑内容，不误触其他操作 |
| 前端-009 | 接口失败 | 模拟查询或保存失败 | 显示错误提示，保留当前页面状态 |
| 前端-010 | 长文本展示 | 使用超长用户名或邮箱 | 单行省略，悬浮可查看完整内容 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 分页查询 | 传入条件、page、page_size | 返回分页记录和总数，分页边界正确 |
| 后端-002 | 新增用户 | 提交合法用户信息 | 创建成功，密码等敏感信息不回传 |
| 后端-003 | 唯一性校验 | 重复邮箱或用户名提交 | 返回业务错误，不产生重复数据 |
| 后端-004 | 修改用户 | 修改用户归属和状态 | 数据更新成功，更新时间正确 |
| 后端-005 | 跨租户校验 | 使用其他租户用户 ID 修改 | 返回 403 或 404，不允许跨租户操作 |
| 后端-006 | 参数校验 | 提交非法邮箱、空名称、非法状态 | 返回 422 或统一业务错误 |
| 后端-007 | 权限校验 | 非平台管理员调用管理接口 | 返回 403 |

## 4. 重点异常

- 租户或组织不存在时不能保存用户。
- 禁用当前登录用户后，后续请求必须重新进行认证状态校验。
