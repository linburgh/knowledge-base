# 自主监控总览状态前端测试用例

## 测试范围

验证监控总览在正常数据、全部空数据、单模块空数据、接口异常、部分失败和数据过期情况下的展示、操作和状态边界。测试字段、提示语和交互以 [`监控总览空数据与异常状态交互原型.html`](../自主监控/监控总览空数据与异常状态交互原型.html) 为准。

## 测试数据

| 数据编号 | 场景说明 |
| --- | --- |
| `MON-OVERVIEW-NORMAL` | 所有模块返回完整有效数据 |
| `MON-OVERVIEW-EMPTY` | 接口成功，所有模块数组为空，`data_status=empty` |
| `MON-OVERVIEW-MODULE-EMPTY` | 业务状态和链路状态为空，其他模块成功 |
| `MON-OVERVIEW-ERROR` | 总览或模块接口返回 500 |
| `MON-OVERVIEW-PARTIAL` | 运行状态过期、资源容量失败、链路状态数据不完整 |

## 验收标准

- 空数据、接口失败、数据过期和无权限四类状态语义清晰且互不替代。
- 模块级失败不覆盖其他成功模块，全局失败不残留伪实时内容。
- 所有重试操作保留当前查询范围和时间窗口。
- 图表空数据不绘制人为零值，统计失败不显示为正常。
- 页面状态与原型、需求、接口 `data_status` 字段和实施方案保持一致。
