# 三个 Agent Harness 整改测试用例

## 测试目标

验证知识库问答、自主评测和自主监控三个 Agent 完成 Harness 整改后，生产调用真实经过独立入口、Skill、Runtime、Policies、工具注册和结果校验，并覆盖正常、边界、异常、权限、状态、数据一致性和兼容性。本文对应 [`三个 Agent Harness 工程整改方案`](../三个Agent%20Harness工程整改方案.md)。

## 测试范围

- `app/agents/knowledge/`
- `app/agents/evaluation/`
- `app/agents/monitoring/`
- `app/schemas/agent.py`、`app/schemas/evaluation.py`、`app/schemas/monitoring.py`
- Chat Service、Evaluation Worker、Monitoring Service 的 Agent 调用适配
- 三个 Agent 的跨域公开协议和数据范围隔离

## 测试约定

- 状态统一使用“待实施、通过、失败、阻塞”。
- 模型、工具、超时和异常使用可控替身或故障注入自行构造。
- 真实模型场景使用测试配置，不在日志或报告中记录密钥和完整业务内容。
- 权限测试覆盖平台、租户、组织、知识库、会话和评测任务范围。
- 仅检查目录存在不能证明 Harness 验收通过，必须同时验证真实运行链。
