# 前端列表表头样式测试用例

## 测试目标

验证 `knowledge-base-web` 所有业务模块列表的表头字号统一为 13px，且 Element Plus 表格、原生表格和选择弹层内表格的样式一致。

## 测试用例

| 用例编号 | 前置条件 | 测试数据 | 操作步骤 | 预期结果 | 验收状态 |
| --- | --- | --- | --- | --- | --- |
| FE-TABLE-HEADER-001 | 前端已加载全局主题 | 平台、知识库、自主评测、自主监控中至少各有一页列表数据 | 依次打开各模块列表，通过浏览器计算样式检查 `.el-table th.el-table__cell` | 所有 Element Plus 列表表头的 `font-size` 计算值均为 `13px` | 待执行 |
| FE-TABLE-HEADER-002 | 知识库工作区或其他原生表格可访问 | 正常列表数据 | 检查 `.data-table th` 的浏览器计算样式 | 原生列表表头的 `font-size` 计算值为 `13px` | 待执行 |
| FE-TABLE-HEADER-003 | 候选成员、组织或权限选择器可打开 | 候选数据不为空 | 打开选择器，检查内部表格表头计算样式 | 弹层内表格继承全局表头字号，计算值为 `13px` | 待执行 |
| FE-TABLE-HEADER-004 | 列表接口返回空数组 | `items=[]`、`total=0` | 打开空数据列表并检查表头 | 空状态不改变表头字号，仍为 `13px` | 待执行 |
| FE-TABLE-HEADER-005 | 使用普通用户、租户管理员和平台管理员分别登录 | 不同角色可见列不同 | 分别访问授权范围内的列表并检查表头 | 权限导致的列显隐不影响全局 13px 表头字号，不展示越权数据 | 待执行 |

## 验收标准

- `src/styles/common.css` 中 Element Plus 表格表头公共样式为 13px。
- `src/styles.css` 中 `.data-table` 和 `.prototype-el-table` 表头样式为 13px。
- 业务页面不存在将列表表头重置为其他字号的局部样式。
- `npm run format:check`、`npm run type-check` 和 `npm run build` 全部通过。
