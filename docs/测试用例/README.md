# 测试用例文档目录

本目录用于评审知识库系统各菜单的前后端测试用例。每个菜单独立维护一份测试用例文档，前端用例包含页面展示、交互、表单校验、加载状态、空状态和异常提示；后端用例包含接口参数、数据范围、权限、状态流转和异常响应。

本阶段只编写测试用例，不执行测试。评审通过后，再按照文档中的用例编号执行并记录实际结果。

## 用例执行约定

- 用例编号在当前菜单文档内唯一，格式为 `前端-001`、`后端-001`、`权限-001`、`异常-001`。
- 执行前准备测试账号、租户、组织、知识库、文档和模型服务数据；账号密码不写入文档。
- 前端用例需要记录浏览器、分辨率、账号和截图；后端用例需要记录请求参数、响应状态、响应体和服务日志。
- 评审阶段只调整用例，不执行接口调用、页面操作、数据库写入或删除操作。
- 执行结果统一填写：通过、失败、阻塞、未执行，并记录实际结果和缺陷编号。
