# 组织管理测试用例

## 1. 测试范围

验证组织树、组织查询、新增、修改、删除、成员列表、成员添加和组织层级权限。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 组织树加载 | 打开组织管理 | 组织层级、成员数量和状态正确展示 |
| 前端-002 | 查询组织 | 输入组织名称和状态查询 | 返回匹配组织，布局保持流式，不出现横向错位 |
| 前端-003 | 新增组织 | 填写组织名称、编码、上级组织后保存 | 新节点展示在正确层级 |
| 前端-004 | 层级校验 | 选择自身或下级作为上级组织 | 显示错误提示，禁止形成循环 |
| 前端-005 | 修改组织 | 修改组织信息后保存 | 列表和树关系同步更新 |
| 前端-006 | 删除组织 | 点击删除并确认或取消 | 确认后删除，取消不改变数据 |
| 前端-007 | 成员列表 | 点击成员操作 | 打开当前组织成员列表，支持查询和分页 |
| 前端-008 | 添加成员 | 打开待选列表、查询、多选、确认 | 临时选择与最终提交状态正确，取消不保存选择 |
| 前端-009 | 滚动和分页 | 组织较多或成员较多时滚动、翻页 | 只有对应区域滚动，分页按钮状态正确 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 组织树查询 | 查询当前租户组织树 | 只返回当前租户数据，父子关系完整 |
| 后端-002 | 层级新增 | 创建根组织和子组织 | parent_id 正确，不能跨租户挂载 |
| 后端-003 | 循环校验 | 将组织挂到自身或下级 | 返回业务错误，不写入数据 |
| 后端-004 | 成员分页 | 查询组织成员 | 支持关键词、状态、分页，数据范围正确 |
| 后端-005 | 批量添加 | 提交多名成员 | 已存在成员不重复添加，失败时整体回滚 |
| 后端-006 | 删除约束 | 删除有子组织或成员的组织 | 按规则拒绝或先处理依赖，不产生孤儿关系 |
| 权限-001 | 角色范围 | 平台、租户、组织角色分别访问 | 菜单和数据范围符合角色矩阵 |

## 4. 重点异常

- 跨租户组织 ID、用户 ID 必须被拒绝。
- 添加成员接口失败时不能只保存部分成员。
