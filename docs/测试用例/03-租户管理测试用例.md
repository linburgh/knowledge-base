# 租户管理测试用例

## 1. 测试范围

验证租户查询、新增、修改、状态管理、成员查看、资源统计和租户边界。

## 2. 前端测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| 前端-001 | 列表加载 | 打开租户管理 | 列表、查询条件和分页正常展示 |
| 前端-002 | 条件查询 | 输入租户名称和状态查询 | 只展示匹配结果，页码重置为第一页 |
| 前端-003 | 新增校验 | 名称、编码为空或格式非法提交 | 显示字段级提示，阻止提交 |
| 前端-004 | 新增租户 | 填写合法信息保存 | 成功提示，刷新列表并展示新租户 |
| 前端-005 | 修改租户 | 修改名称、描述或状态 | 抽屉回填正确，保存结果同步列表 |
| 前端-006 | 成员列表 | 点击成员列表 | 进入当前租户成员视图，不串租户数据 |
| 前端-007 | 弹层交互 | 打开、关闭抽屉，点击遮罩关闭 | 关闭后表单状态按设计清理或保留 |
| 前端-008 | 加载失败 | 模拟接口失败 | 展示错误提示，不显示本地伪造数据 |

## 3. 后端测试用例

| 编号 | 接口场景 | 操作 | 预期结果 |
|---|---|---|---|
| 后端-001 | 租户分页 | 传入名称、状态、分页参数 | 返回正确分页数据 |
| 后端-002 | 新增租户 | 提交合法租户信息 | 创建租户并初始化必要资源 |
| 后端-003 | 编码唯一 | 提交重复租户编码 | 返回冲突错误，不覆盖旧数据 |
| 后端-004 | 修改状态 | 停用或恢复租户 | 状态更新，相关访问按状态生效 |
| 后端-005 | 跨租户查询 | 非平台管理员查询其他租户 | 返回 403 或过滤为空 |
| 后端-006 | 删除约束 | 删除存在用户、知识库的租户 | 按业务规则拒绝或执行完整级联策略，不产生孤儿数据 |

## 4. 重点异常

- 租户停用后，租户成员不能继续访问租户资源。
- 修改租户失败时事务必须回滚。

## 5. 2026-07-26 自动化执行补充

已执行租户分页、创建、修改、重复编码、必填字段和删除约束。临时租户包含活动知识库时删除返回 HTTP 409；清理依赖后可正常软删除，未产生活动知识库孤儿数据。
