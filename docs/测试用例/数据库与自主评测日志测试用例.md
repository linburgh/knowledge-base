# 数据库与自主评测日志测试用例

## 测试范围

验证数据库统一访问层记录所有 SQL 操作，以及自主评测 Agent 从启动到结束的完整结构化日志。

## 测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| LOG-DB-001 | 查询 SQL 日志 | 执行 `fetch_all`、`fetch_one`、`fetch_val` | 日志包含操作类型、SQL 文本、执行结果和耗时 |
| LOG-DB-002 | 写入 SQL 日志 | 执行 `execute`、`execute_many` | 日志包含写入 SQL、批次摘要、执行结果和耗时 |
| LOG-DB-003 | SQL 异常日志 | 注入数据库执行异常 | 日志包含 SQL 操作类型、异常和耗时，原异常继续抛出 |
| LOG-DB-004 | SQL 敏感信息脱敏 | 使用包含账号、密码或 Token 的参数执行查询 | 日志只记录参数名或脱敏摘要，不记录参数值 |
| LOG-EVAL-001 | Agent 生命周期 | 执行一条正常评测问题 | 日志覆盖 Agent 启动、配置校验、运行时、逐题执行、知识库 Agent 调用、指标计算和结束 |
| LOG-EVAL-002 | Agent 异常生命周期 | 注入超时、重试或问答 Agent 异常 | 日志记录题目编号、尝试次数、异常/超时和最终状态 |
| LOG-EVAL-003 | Worker 生命周期 | 执行自主评测 Worker | 日志覆盖任务准备、问题加载/生成、Agent 执行、结果持久化、成功或失败结束 |
