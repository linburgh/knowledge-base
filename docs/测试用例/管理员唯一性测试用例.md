# 管理员唯一性测试用例

## 1. 规则

- 平台只能有一个有效 `p_super_admin`。
- 每个未删除租户只能有一个有效 `tenant_admin`。
- 每个未删除组织只能有一个有效 `org_admin`。
- 平台超级管理员、租户管理员和组织管理员不能被撤销或降级为导致作用域内没有管理员的状态。

## 2. 测试用例及结果

| 编号 | 测试场景 | 预期结果 | 结果 |
|---|---|---|---|
| ADMIN-001 | 平台已有超级管理员时再次分配 `p_super_admin` | 返回 `409`，原管理员不变 | 通过 |
| ADMIN-002 | 尝试撤销最后一个 `p_super_admin` | 返回 `409`，原管理员保留 | 通过 |
| ADMIN-003 | 租户已有管理员时新增第二个 `tenant_admin` | 返回 `409`，租户仍只有一个管理员 | 通过 |
| ADMIN-004 | 尝试移除或降级最后一个 `tenant_admin` | 返回 `409`，管理员保留 | 通过 |
| ADMIN-005 | 组织已有管理员时新增第二个 `org_admin` | 返回 `409`，组织仍只有一个管理员 | 通过 |
| ADMIN-006 | 尝试移除或降级最后一个 `org_admin` | 返回 `409`，管理员保留 | 通过 |
| ADMIN-007 | 执行数据库唯一性审计脚本 | 每个有效平台、租户和组织的 `active_count` 均为 `1` | 不通过 |

## 3. 数据审计

执行：

```bash
docker compose exec -T postgres psql -U linburgh -d knowledge_base \
  -f scripts/db/check_singleton_admins.sql
```

当前数据库结果：

- 平台超级管理员：`1` 个，符合要求。
- 租户管理员：原租户 `51` 存在 2 个管理员，已保留 `is_primary=true` 的用户 `204`，将用户 `3` 降为普通成员；另有 `50` 个历史租户没有管理员，尚未擅自指定管理员。
- 组织管理员：重复数据不存在；有 `151` 个历史组织没有管理员，尚未擅自指定管理员。

因此，当前数据库对“最多一个”已符合，对“每个有效租户/组织必须恰好一个”仍不通过；缺失管理员需要业务指定具体用户后补齐。
