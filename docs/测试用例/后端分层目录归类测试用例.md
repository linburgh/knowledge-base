# 后端分层目录归类测试用例

## 测试范围

验证平台管理、知识库管理和自主监控 API、Service、DB Repository 的目录归属、导入路径及运行兼容性。自主评测属于平台管理能力，其 Service 与 Repository 归入 `platform/`。

## 测试用例

| 编号 | 前置条件 | 测试数据 | 操作步骤 | 预期结果 | 验收状态 |
| --- | --- | --- | --- | --- | --- |
| SVC-001 | 完成目录迁移 | `app/core/services/` | 检查根目录 Python 文件 | 除 `__init__.py` 外不存在平铺业务 Service | 通过 |
| SVC-002 | 完成目录迁移 | 三个业务包的模块清单 | 对比目录内模块与预期归属 | 模块无缺失、无重复、无跨域错放 | 通过 |
| SVC-003 | Python 环境可用 | 三个业务包内全部模块 | 逐个动态导入模块 | 全部模块成功导入，无旧路径依赖 | 通过 |
| SVC-004 | 测试依赖可用 | API、Worker、Agent、动态采集配置 | 执行后端全量单元测试 | 调用链、Mock 与动态模块加载保持正常 | 通过，119 项 |
| SVC-005 | 文档已同步 | Worker 与自主监控实施文档 | 搜索旧 Service 路径 | 不再引用已迁移的旧模块路径 | 通过 |
| DB-001 | 完成 DB 目录迁移 | `app/db/` | 检查根目录 Python 文件 | 根目录只保留数据库基础设施 | 通过 |
| DB-002 | 完成 DB 目录迁移 | 三个 Repository 包的模块清单 | 对比目录内模块与预期归属 | 模块无缺失、无重复、无跨域错放 | 通过 |
| DB-003 | Python 环境可用 | 三个 Repository 包内全部模块 | 逐个动态导入模块 | 全部模块成功导入，无旧路径依赖 | 通过 |

## 执行方式

```bash
.venv/bin/python -m unittest tests.test_service_directory_structure
.venv/bin/python -m unittest tests.test_db_directory_structure
.venv/bin/python -m unittest tests.test_api_directory_structure
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
```
