# 自主监控总览状态后端测试用例

## 测试范围

验证 `GET /api/v1/monitoring/overview` 对事件、告警和运行快照执行独立查询与失败收敛，并向前端返回可执行的总览状态、模块状态和脱敏错误说明。

## 用例清单

| 用例编号 | 前置条件 | 测试数据 | 操作步骤 | 预期结果 | 验收状态 |
| --- | --- | --- | --- | --- | --- |
| `MON-BE-OV-STATE-001` | 具有自主监控权限 | 三类数据源均返回空数组 | 调用总览 Service | 全局和六个模块均返回 `empty`，`section_errors` 为空 | 通过 |
| `MON-BE-OV-STATE-002` | 具有自主监控权限 | 事件查询失败，告警为空，运行快照成功 | 调用总览 Service | 全局返回 `partial`；运行状态返回 `partial`；资源容量保持 `ready`；事件依赖模块返回 `error` | 通过 |
| `MON-BE-OV-STATE-003` | 具有自主监控权限 | 三类数据源全部抛出异常 | 调用总览 Service | 接口正常收敛响应；全局和六个模块均返回 `error` | 通过 |
| `MON-BE-OV-STATE-004` | 数据源异常包含连接细节 | 异常消息包含模拟敏感内容 | 查看 `section_errors` | 只返回稳定中文说明，不返回原始异常、SQL、参数或连接信息 | 通过 |
| `MON-BE-OV-STATE-005` | 创建真实 FastAPI 路由并覆盖测试认证 | 三类数据源均为空 | 通过 ASGI HTTP 调用 `/api/v1/monitoring/overview` | HTTP 200；响应包含 `data_status`、`section_statuses` 和 `section_errors` | 通过 |
| `MON-BE-OV-STATE-006` | 无自主监控权限 | 任意数据 | 调用总览接口 | 返回 403，不泄露模块数据 | 待执行 |
| `MON-BE-OV-STATE-007` | 租户管理员已登录 | 同时存在多个租户数据 | 调用当前租户总览 | 只查询并返回当前租户范围数据 | 待真实数据执行 |
| `MON-BE-OV-STATE-008` | 开发后端和数据库正常运行 | 创建可撤销的临时平台管理员认证会话 | 调用 `127.0.0.1:28003/api/v1/monitoring/overview`，完成后撤销会话 | HTTP 200；返回全局和六个模块状态；不写入演示监控数据 | 通过 |
| `MON-BE-OV-STATE-009` | 数据库仅存在窗口外历史数据 | 分别选择 `15m`、`1h`、`6h`、`24h` 和 `7d` | 调用总览接口 | 只返回对应窗口内事件、告警和快照；窗口外数据不参与状态与图表 | 通过 |
| `MON-BE-OV-STATE-010` | 平台管理员具有当前租户上下文 | 分别传入 `scope_key=platform` 和 `scope_key=tenant` | 调用总览接口 | 平台范围和当前租户范围正确切换，不泄露其他租户数据 | 待执行 |
| `MON-BE-OV-STATE-011` | 任意授权用户 | 传入非法 `time_range` 或 `scope_key` | 调用总览接口 | 返回 400，不降级为全量查询 | 通过 |
| `MON-BE-OV-STATE-012` | 存在超过五项运行快照 | 同时包含健康、预警、故障、过期和未知服务 | 调用总览 Service | `runtime_status` 最多返回五项；故障、预警、过期和获取失败服务优先，同风险等级按预置优先级排序 | 通过 |
| `MON-BE-OV-STATE-013` | 存在已登记和未知资源编码 | 运行快照包含多类资源编码 | 查看 `runtime_status` | 每项均返回 `resource_name`；已登记资源名称为四个中文字，未知编码返回“其他服务”，不向页面透传英文编码作为名称 | 通过 |
| `MON-BE-OV-STATE-014` | 存在当前快照但历史桶无探针事件 | 分别构造有事件和无事件的时间桶 | 调用总览 Service | 有事件时间格按最严重状态着色，无事件时间格返回 `unknown`，当前快照只允许补充其实际探测时间所在桶 | 通过 |
| `MON-BE-OV-STATE-015` | 当前时间固定且选择不同时窗 | 依次选择 `15m`、`1h`、`6h`、`24h`、`7d` | 查看 `timeline` | 时间轴与查询窗口边界对齐，分别使用 5 分钟、5 分钟、30 分钟、2 小时和 12 小时粒度；`time` 为带时区 ISO 8601 时间 | 通过 |
| `MON-BE-OV-STATE-016` | 四类容量快照存在 | 文件和向量配额可配置或未配置 | 调用总览 Service | 固定返回数据库连接、队列容量、文件存储和向量存储；无配额项返回 `usage=null` 和 `data_status=empty`，不返回本地暂存空间 | 通过 |
| `MON-BE-OV-STATE-018` | PostgreSQL 与应用连接池均可访问 | 数据库实例 `max_connections` 大于单进程连接池上限 | 执行 `capacity.database` 探针 | `used` 统计 `pg_stat_activity` 当前实例连接总数，`capacity` 读取 `max_connections`；连接池 size、idle、max 只进入详情字段，不作为总览分子或分母 | 通过 |

## 自动化位置

- `tests/test_monitoring_overview_states.py`：空数据、部分失败、全部失败、错误脱敏和 HTTP 响应合同。
- `tests/test_monitoring_alert_flow.py`：事件、告警、通知和监控 Agent 原有全流程回归。
