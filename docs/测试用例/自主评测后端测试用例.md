# 自主评测后端测试用例

## 1. 测试范围

覆盖知识库问答评测 Agent 后端的配置加载、问题导入与生成、两个 Agent Harness、LangGraph、Worker、指标、报告、优化复测、数据库、API、权限、安全、审计和异常处理。

依据文档：

- [知识库问答评测Agent需求与实施方案.md](../自主评测/知识库问答评测Agent需求与实施方案.md)
- [自主评测后端开发实施方案.md](../自主评测/自主评测后端开发实施方案.md)

## 2. 测试环境和数据

- 测试用户：平台超级管理员、普通平台角色、租户角色、组织角色、访客。
- 测试知识库：一个有效且有文档的知识库、一个空知识库、一个不存在或无权限知识库。
- 问题文件：合法 TXT、JSON、JSONL；空文件、重复问题、非法 JSON、超大文件和无 `question` 字段文件。
- 配置模式：外部导入、仅知识库生成、仅描述生成、描述与知识库结合生成。
- 运行参数：并发 1 和并发 3；正常超时、超时、重试 0 次和受限重试。
- 结果样本：正常回答、无引用、降级、超时、模型错误、检索为空、任务级异常。

## 3. 测试用例字段

| 字段 | 说明 |
|---|---|
| 用例编号 | 唯一编号，如 `BE-EVAL-001` |
| 用例名称 | 可验证的业务行为 |
| 优先级 | P0、P1、P2 |
| 前置条件 | 环境、用户、任务和数据 |
| 操作步骤 | 可执行的请求或操作 |
| 预期结果 | 状态、数据、错误码和副作用 |
| 状态 | 未执行、通过、失败、阻塞 |

## 4. 配置、数据集和两个 Agent

| 编号 | 用例 | 优先级 | 前置条件与步骤 | 预期结果 |
|---|---|---:|---|---|
| BE-EVAL-001 | 加载默认 YAML 配置 | P0 | 使用 `--config` 指向合法 `etc/evaluation.yaml` | 正确转换为 `EvaluationConfig`，默认门禁生效，不读取 `app.yaml` 评测节点 |
| BE-EVAL-002 | 配置优先级 | P1 | 同时提供命令行、YAML 和系统默认值 | 按命令行 > YAML > 默认值覆盖，结果可记录 |
| BE-EVAL-003 | 配置敏感信息拦截 | P0 | 在配置中加入 Token、API Key 或密码 | 配置拒绝或脱敏，敏感值不进入日志和快照 |
| BE-EVAL-004 | 导入 TXT 问题 | P0 | 提交每行一个问题的 TXT | 解析成功，生成问题序号、来源 `imported` 和数量摘要 |
| BE-EVAL-005 | 导入 JSON/JSONL | P0 | 提交合法对象、`case_id`、可选标准答案和标签 | 字段校验通过，扩展字段正确保留 |
| BE-EVAL-006 | 非法问题文件 | P0 | 提交空文件、非法 JSON、缺少 `question` 或全空问题 | 返回 `DATASET_INVALID`，不创建可执行运行 |
| BE-EVAL-007 | 重复问题处理 | P1 | 提交重复文本和重复 `case_id` | 按设计去重或拒绝，结果中记录处理方式，不能静默丢失 |
| BE-EVAL-008 | 生成问题：知识库 | P0 | `source=generated`、`business_scope.source=knowledge_base` | 根据知识库内容生成指定数量问题，记录 `question_basis=knowledge_base` |
| BE-EVAL-009 | 生成问题：描述 | P0 | 仅提供外部业务描述 | 根据描述生成问题，记录 `question_basis=description` |
| BE-EVAL-010 | 生成问题：组合 | P0 | 同时提供知识库和业务描述 | 结合两类内容生成，记录 `question_basis=both` |
| BE-EVAL-011 | 超出知识库范围的问题 | P1 | 描述中包含知识库未覆盖内容 | 不由生成阶段强行过滤，可用于覆盖率和拒答测试 |
| BE-EVAL-012 | 两个 Agent 独立入口 | P0 | 分别调用 `app.agents.knowledge.agent` 和 `app.agents.evaluation.agent` | 两个入口、Runtime、Policies 和工具注册独立，评测 Agent 不复制普通 RAG |
| BE-EVAL-013 | 评测调用问答 Agent 协议 | P0 | 执行一道测试题 | 仅通过公开结构化协议调用 knowledge Agent，获得答案、引用、状态、终止原因、命中数和耗时 |
| BE-EVAL-014 | Agent 私有实现隔离 | P1 | 尝试从评测 Agent 调用 knowledge Agent 私有 Prompt、函数或模型 | 调用边界被拒绝或代码检查失败，不能形成隐式依赖 |

## 5. LangGraph 和 Worker

| 编号 | 用例 | 优先级 | 操作步骤 | 预期结果 |
|---|---|---:|---|---|
| BE-EVAL-015 | 正常导入评测流程 | P0 | 创建运行并执行合法问题集 | 依次完成加载、校验、冻结、分发、执行、收集、指标、门禁和报告节点 |
| BE-EVAL-016 | 正常生成评测流程 | P0 | 创建生成模式运行 | 先生成并校验问题，再交给 knowledge Agent 执行，不将生成内容当作答案 |
| BE-EVAL-017 | 并发限制 | P0 | 设置并发 3，提交超过 3 道问题 | 同时执行数不超过 3，所有题最终都有结果 |
| BE-EVAL-018 | 单题异常继续执行 | P0 | 让一题模型异常或工具异常 | 该题写入 `error`，其他题继续，运行不因单题异常直接失败 |
| BE-EVAL-019 | 单题超时 | P0 | 设置短超时并让一题超时 | 该题写入 `timeout` 和错误摘要，其他题继续 |
| BE-EVAL-020 | 降级结果 | P0 | 让 knowledge Agent 返回降级结果 | 写入 `fallback`，不计入正常成功回答，运行继续 |
| BE-EVAL-021 | 任务级异常 | P0 | 让配置校验、知识库校验或数据库收尾失败 | 运行进入 `failed`，保存结构化错误，不伪造指标和通过结论 |
| BE-EVAL-022 | Worker 重启恢复 | P1 | 运行中停止并重启 Worker | 已完成题目不重复写入，未完成题目继续，最终结果可追溯 |
| BE-EVAL-023 | 重复执行幂等 | P0 | 重复提交同一运行或重复消费 Worker 消息 | 不产生重复逐题结果或重复运行状态，唯一键和状态校验生效 |
| BE-EVAL-024 | 运行状态更新 | P0 | 观察 pending、running、completed、failed、cancelled | 状态按合法转换变化，不能从终态回到 running |

## 6. 指标、门禁和报告

| 编号 | 用例 | 优先级 | 操作步骤 | 预期结果 |
|---|---|---:|---|---|
| BE-EVAL-025 | 基础指标计算 | P0 | 执行含成功、错误、降级、引用的题集 | 正确计算成功率、错误率、降级率、引用率和样本数 |
| BE-EVAL-026 | P50/P95/P99 | P1 | 提供多组耗时 | 按有效样本计算分位耗时，单位统一为毫秒 |
| BE-EVAL-027 | 高级指标无标注 | P0 | 只提供问题，没有标准答案/文档标注 | Recall@K、MRR、Answer Correctness 等标记无法评估，不伪造数值 |
| BE-EVAL-028 | 门禁通过 | P0 | 所有强制指标满足阈值 | 结论为 `passed` |
| BE-EVAL-029 | 门禁不通过 | P0 | 任一强制指标不满足阈值 | 结论为 `failed`，报告列出不合格指标和证据 |
| BE-EVAL-030 | 指标无法计算 | P0 | 无有效样本或缺少高级指标标注 | 相关指标为不可用，整体结论按规则为 `indeterminate`，不默认通过 |
| BE-EVAL-031 | 报告完整性 | P0 | 查询完成运行报告 | 包含任务、数据集、配置摘要、指标、失败样品、异常列表、基线和总体结论 |
| BE-EVAL-032 | 报告脱敏 | P0 | 配置和结果中包含敏感值或本机路径 | 报告、快照和日志不包含敏感值 |
| BE-EVAL-033 | 逐题结果完整性 | P0 | 查询逐题结果和单题详情 | 返回问题、来源、答案状态、引用、耗时、终止原因、错误和单题指标 |

## 7. API、数据库、权限和审计

| 编号 | 用例 | 优先级 | 操作步骤 | 预期结果 |
|---|---|---:|---|---|
| BE-EVAL-034 | 任务分页查询 | P0 | 传入名称、知识库、状态、结论和分页参数 | 返回统一 `items/total/page/page_size`，只展示未删除任务 |
| BE-EVAL-035 | 创建任务事务回滚 | P0 | 在任务写入或审计写入中制造异常 | 任务和关联写入全部回滚，不留下半成品 |
| BE-EVAL-036 | 创建运行事务 | P0 | 并发请求创建同一任务运行 | 只能创建一条 pending/running，`run_no` 不重复 |
| BE-EVAL-037 | 运行归属校验 | P0 | 使用其他任务的 `run_id` 查询 | 返回业务错误或 404/403，不泄露结果 |
| BE-EVAL-038 | 逻辑删除 | P0 | 删除 active 任务后查询和执行 | 列表不再展示，不能新增运行，历史结果按策略保留 |
| BE-EVAL-039 | 非超级管理员 | P0 | 用普通平台、租户、组织和访客请求所有接口 | 统一 403，不泄露任务是否存在 |
| BE-EVAL-040 | 运行用户权限 | P0 | 评测用户无知识库权限 | 逐题记录权限错误，不能使用管理员身份绕过 |
| BE-EVAL-041 | 审计日志 | P1 | 创建、执行、查看、优化、复测、保存草稿和删除 | 每项操作都有审计记录，敏感信息已脱敏 |
| BE-EVAL-042 | Repository 分层 | P1 | 检查 Service 和 DB 调用 | Service 通过对应表模块访问 DB，不由 API 直接操作模型或数据库 |

## 8. 优化建议和复测

| 编号 | 用例 | 优先级 | 操作步骤 | 预期结果 |
|---|---|---:|---|---|
| BE-EVAL-043 | 生成优化建议 | P0 | 对存在失败样品的完成运行生成建议 | 返回问题现象、证据、建议、影响指标、优先级、置信度和人工确认标记 |
| BE-EVAL-044 | 无法计算时的建议 | P0 | 对高级指标不可用的运行生成建议 | 只输出数据/链路补充建议，不虚构参数优化结论 |
| BE-EVAL-045 | 同批问题复测 | P0 | 使用候选方案启动复测 | 复测绑定原运行问题集合，产生独立复测运行记录 |
| BE-EVAL-046 | 复测效果提升 | P0 | 让关键指标提升 | 方案状态为可采用，记录前后指标，允许保存草稿 |
| BE-EVAL-047 | 复测无效或退化 | P0 | 让关键指标不变或变差 | 状态为 `ineffective` 或 `regressed`，不允许标记建议采用 |
| BE-EVAL-048 | 保存优化草稿 | P0 | 复测完成后保存草稿 | 保存候选配置和结果，不修改正式配置、不自动发布 |
| BE-EVAL-049 | 文档/索引类建议确认 | P0 | 生成文档修改、索引重建或业务规则建议 | `requires_confirmation=true`，报告明确人工确认要求 |

## 9. 后端验收

- [ ] 两个 Agent 均为独立 Harness 目录和独立入口。
- [ ] 导入和自主生成两种问题来源均可执行。
- [ ] 单题异常、超时和降级不丢失整批结果。
- [ ] 运行状态、逐题结果、指标、报告和配置快照可追溯。
- [ ] 高级指标缺少标注时显示无法评估。
- [ ] 优化建议、复测和保存草稿不自动修改正式配置。
- [ ] 非超级管理员无法调用接口。
- [ ] 测试数据、日志和报告不包含敏感信息。
