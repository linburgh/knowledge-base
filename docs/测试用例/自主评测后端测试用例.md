# 自主评测后端测试用例

## 1. 测试范围

覆盖知识库问答评测 Agent 后端的配置加载、问题导入与生成、两个 Agent Harness、LangGraph、Worker、指标、报告、优化复测、数据库、API、权限、安全、审计和异常处理。

依据文档：

- [知识库问答评测Agent需求与实施方案.md](../自主评测/知识库问答评测Agent需求与实施方案.md)
- [自主评测后端开发实施方案.md](../自主评测/自主评测后端开发实施方案.md)

## 2. 测试环境和数据

- 测试用户：平台超级管理员、普通平台角色、租户角色、组织角色、访客。
- 测试知识库：一个有效且有文档的知识库、一个空知识库、一个不存在或无权限知识库。
- 问题文件：合法 TXT、JSON、JSONL；空文件、重复问题、非法 JSON、超大文件和无 `question` 字段文件。
- 配置模式：外部导入、仅知识库生成、仅描述生成、描述与知识库结合生成。
- 运行参数：并发 1 和并发 3；正常超时、超时、重试 0 次和受限重试。
- 结果样本：正常回答、无引用、降级、超时、模型错误、检索为空、任务级异常。

## 3. 测试用例字段

| 字段     | 说明                       |
| -------- | -------------------------- |
| 用例编号 | 唯一编号，如 `BE-EVAL-001` |
| 用例名称 | 可验证的业务行为           |
| 优先级   | P0、P1、P2                 |
| 前置条件 | 环境、用户、任务和数据     |
| 操作步骤 | 可执行的请求或操作         |
| 预期结果 | 状态、数据、错误码和副作用 |
| 状态     | 未执行、通过、失败、阻塞   |

## 3.1 本轮执行边界

- 自动化执行：Python 目标文件编译、现有后端单元测试、接口路由加载和数据库权限核验。
- 联调执行：平台超级管理员真实接口的任务创建、编辑、执行、结果查询和状态冲突。
- 手工或环境依赖：Worker 真实模型执行、超时/降级注入、非超级管理员多角色矩阵和事务故障注入。
- 每个 P0 用例执行后记录请求、响应状态、数据库副作用和最终状态，不以“页面无报错”替代接口验证。

## 9. 后端验收

- [ ] 两个 Agent 均为独立 Harness 目录和独立入口。
- [ ] 导入和自主生成两种问题来源均可执行。
- [ ] 单题异常、超时和降级不丢失整批结果。
- [ ] 运行状态、逐题结果、指标、报告和配置快照可追溯。
- [ ] 高级指标缺少标注时显示无法评估。
- [ ] 优化建议、复测和保存草稿不自动修改正式配置。
- [ ] 非超级管理员无法调用接口。
- [ ] 测试数据、日志和报告不包含敏感信息。
