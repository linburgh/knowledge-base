# 无极树演示数据测试用例

## 测试范围

验证组织树能够承载一个根节点、十级深度和每级十万直接子节点的百万级演示数据，并保证造数过程隔离、可验证、可重复执行。

## 数据结构

- 独立租户编码：`infinite-tree-demo`。
- 根节点名称：`无极树演示节点`。
- 根节点深度为 0，最深节点位于第 10 级。
- 第 0～9 级主链节点分别拥有 100,000 个直接子节点。
- 每级选择编号 `000000` 的子节点继续向下展开，其余节点为同级演示节点。
- 第 10 级主链节点为叶子节点。
- 节点总数：`1 + 10 × 100,000 = 1,000,001`。
- 所有数据仅写入独立演示租户，不修改其他租户的组织数据。

## 执行命令

```bash
.venv/bin/python -m tests.performance.seed_infinite_organization_tree
```

脚本检测到完整数据时只做校验，不重复插入；检测到部分数据时拒绝继续。需要重建独立演示租户的数据时执行：

```bash
.venv/bin/python -m tests.performance.seed_infinite_organization_tree --reset
```
