# 智能售前讲解员需求设计文档

## 1. 文档说明

### 1.1 项目名称

智能售前讲解员

### 1.2 项目定位

智能售前讲解员是面向销售、售前顾问和解决方案架构师的客户演示 Agent。它能够理解客户背景和商机阶段，解析产品 PPT 与配套资料，在客户会议中按照页面进行讲解，实时回答客户问题，并在会后生成会议纪要、客户关注点和跟进任务。

产品不是单纯的 PPT 播放器，也不是无边界的自动问答机器人，而是一个由售前人员控制、以产品资料为事实依据、具备人工接管和承诺风险控制能力的智能演示工作台。

### 1.3 设计原则

1. 讲解内容必须有资料来源，不能把模型猜测当作产品事实。
2. 默认由售前人员控制演示节奏，AI 负责建议、讲解和辅助回答。
3. 价格、交付周期、定制范围、合规承诺和竞品结论必须经过人工确认。
4. 客户数据、会议录音、PPT 和内部资料必须按组织、项目和客户范围隔离。
5. 任何回答都要区分已确认事实、合理推断和待确认事项。
6. 会议中断网、模型异常或设备异常时，售前人员仍可以继续手动讲解。

### 1.4 文档范围

本文覆盖业务目标、角色、场景、PPT 解析、演示流程、Agent 编排、页面模块、接口、数据、权限、状态、异常、安全、评测、部署和实施计划。

## 2. 产品目标与范围

### 2.1 产品目标

- 将产品 PPT 转换为可讲解、可检索、可审核的页面知识。
- 根据客户行业、规模、需求和商机阶段生成个性化讲解提纲。
- 支持辅助讲解、AI 自动讲解和现场问答三种工作模式。
- 支持客户打断、语音提问、文字提问和实时人工接管。
- 在回答中提供来源页、产品文档、案例和规则依据。
- 自动识别不应直接对客户承诺的内容。
- 将会议过程沉淀为会议纪要、需求变化、异议、风险和跟进任务。
- 支持多产品、多版本 PPT、多语言和不同客户演示策略。

### 2.2 产品范围

包括：

- 客户与商机资料管理。
- 产品 PPT 上传、解析、版本和审核。
- 页面级讲解稿生成和人工编辑。
- 产品能力、案例、竞品和交付规则知识库。
- 演示会话控制和实时问答。
- 语音识别、语音合成和文字模式。
- 客户问题、回答来源和风险提示。
- 会议纪要和跟进任务。
- 讲解质量、问题命中率和客户关注点统计。

不包括：

- 自动签署合同或自动报价。
- 未经人工确认自动承诺交付和定制范围。
- 默认自动修改或发布产品 PPT 原文件。
- 在未授权情况下读取客户通讯录、会议内容或私有仓库。

## 3. 用户角色与权限

| 角色 | 能力 |
|---|---|
| 平台管理员 | 管理组织、模型、语音服务、全局安全策略和审计。 |
| 组织管理员 | 管理成员、客户数据范围、产品资料、PPT 版本和组织级策略。 |
| 售前顾问 | 创建演示、编辑讲解稿、执行现场讲解、回答客户问题和维护跟进。 |
| 销售人员 | 管理客户和商机，发起演示，查看纪要和跟进任务。 |
| 解决方案架构师 | 审核技术方案、产品能力、架构讲解和交付边界。 |
| 产品专家 | 维护产品能力、版本说明、限制条件和常见问答。 |
| 销售经理 | 查看演示记录、客户关注点、商机推进和团队统计。 |
| 只读成员 | 查看授权客户、PPT、演示记录和报告，不得发起或修改演示。 |
| 系统 Worker | 执行解析、索引、转写、Agent 和报告任务，不拥有业务访问权限。 |

权限分为组织、客户、商机、资料、演示操作、会议数据和管理配置七个范围。Worker 必须使用任务创建时的权限快照，不能因为后台任务身份扩大客户资料访问范围。

## 4. 核心业务场景

### 4.1 标准产品介绍

售前人员选择客户和产品 PPT，系统根据客户画像生成讲解路线，按页面辅助讲解产品定位、核心能力、架构、案例和下一步行动。

### 4.2 行业方案演示

系统根据客户行业和需求，自动推荐相关页面、行业案例、方案模块和注意事项，允许售前人员隐藏不适用页面或调整讲解顺序。

### 4.3 客户实时提问

客户通过语音或文字提出问题，系统在当前 PPT、产品能力库、案例库和交付规则中检索，生成回答、来源和风险提示。售前人员可以直接播报、编辑后播报或接管回答。

### 4.4 方案答疑与异议处理

系统识别客户对价格、竞品、交付、性能、安全和定制的异议，推荐经过审核的回答话术和证据，不允许模型自行生成未经确认的商业承诺。

### 4.5 会后复盘

系统根据演示过程和问答记录提取客户关注点、明确需求、待确认事项、竞争信息、风险和下一步任务，生成会议纪要供人工确认后保存。

## 5. 总体业务流程

```text
客户/商机准备
  -> 选择产品与 PPT 版本
  -> 解析页面和建立知识索引
  -> 生成讲解路线与页面讲解稿
  -> 售前审核演示内容
  -> 创建演示会话
  -> 按页讲解与实时问答
  -> 人工确认或接管高风险回答
  -> 结束会议并生成纪要
  -> 确认需求、风险和跟进任务
```

### 5.1 演示准备

1. 选择客户、商机、产品和 PPT 版本。
2. 系统加载客户行业、已知需求、历史会议和商机阶段。
3. 用户配置演示目标、预计时长、重点页面和禁用页面。
4. 系统生成页面讲解提纲、推荐案例、预计问题和风险提示。
5. 售前人员审核并修改讲解内容，确认后创建演示会话。

### 5.2 演示执行

1. 演示会话加载 PPT 页面、讲解稿和资料来源。
2. 售前人员选择辅助或自动讲解模式。
3. 当前页面讲解完成后，系统等待下一页指令或自动推进。
4. 客户提问时暂停当前讲解，进入问题识别和回答流程。
5. 对高风险回答显示人工确认提示，未确认时不得自动播报。
6. 所有问题、回答、来源、人工修改和接管动作进入会话记录。

### 5.3 会后处理

- 生成会议转写和摘要。
- 提取需求、异议、竞争信息和未决问题。
- 标记需求可信度和来源时间。
- 生成跟进任务、负责人和截止时间。
- 由售前或销售确认后写入客户和商机记录。

## 6. PPT 解析与内容管理

### 6.1 PPT 上传

支持 PPTX、PDF 和已批准的图片型演示材料。上传时校验文件大小、类型、病毒、敏感信息和所属组织。

PPT 版本至少记录：

- 产品、行业和适用客户。
- 版本号、生效时间和失效时间。
- 语言和地区。
- 创建人、审核人和审核时间。
- 来源文件哈希。
- 是否允许对外演示。

### 6.2 页面解析内容

每页解析：

- 页码、标题和正文。
- 文本框、表格、图表和备注。
- 图片和图片文字识别结果。
- 页面视觉摘要和关键概念。
- 产品能力、案例、指标和限制条件。
- 页面之间的前后关系。
- 可讲解时长和适合的客户阶段。

### 6.3 页面审核

解析结果必须经过状态管理：

```text
上传中 -> 解析中 -> 待审核 -> 已通过 -> 已发布 -> 已归档
                         \-> 解析失败
```

未经审核或已过期的 PPT 页面不能作为对外自动讲解事实来源。内部演示可以由有权限人员明确选择未发布版本，并在界面显示风险提示。

### 6.4 页面知识索引

页面索引分为：

- 页面正文索引。
- 页面讲解稿索引。
- 页面图片和图表描述索引。
- 产品能力和限制条件索引。
- 页面关联案例索引。
- 页面常见问题索引。

检索结果必须返回 `ppt_id`、版本、页码、内容类型和有效期，避免引用过期材料。

## 7. 演示模式设计

### 7.1 辅助讲解模式

默认模式，售前人员拥有节奏控制权：

- AI 显示当前页讲解稿和来源。
- 售前人员点击“开始讲解”后播放语音或自行阅读。
- 支持暂停、继续、上一页、下一页和重新生成讲解。
- AI 推荐下一页和可能的问题，但不自动改变页面顺序。
- 客户问题默认先显示回答建议，由售前决定是否播报。

### 7.2 AI 自动讲解模式

适用于标准化产品介绍：

- 按预设路线自动播放和讲解。
- 支持预计时长控制和页面跳过。
- 客户打断时自动暂停并进入问答。
- 对价格、交付、定制、合规和竞品问题强制人工确认。
- 任何时候支持一键暂停和人工接管。

### 7.3 现场问答模式

- 支持麦克风语音输入、文字输入和外部会议转写输入。
- 显示问题转写文本和识别置信度。
- 展示问题分类、回答建议、引用来源和风险等级。
- 支持“直接播报”“编辑后播报”“人工回答”“暂不回答”。
- 问答结束后支持返回原讲解页面或跳转推荐页面。

### 7.4 断网和人工接管

演示工作台应保留最近使用的 PPT、讲解稿和基础操作能力。网络或模型不可用时：

- PPT 仍可翻页和查看。
- 已生成讲解稿仍可阅读。
- 语音播报失败时显示文字内容。
- 问答失败时展示“请人工回答”，不显示猜测内容。
- 会话恢复后再补传转写和操作事件。

## 8. Agent 系统设计

### 8.1 Agent 角色

| Agent | 职责 |
|---|---|
| Session Orchestrator Agent | 编排准备、讲解、问答和会后处理流程。 |
| Customer Context Agent | 汇总客户、商机、行业、历史会议和当前目标。 |
| PPT Understanding Agent | 理解页面结构、图表、图片和页面关系。 |
| Presentation Planner Agent | 生成讲解路线、页面顺序、时间分配和跳页建议。 |
| Speaker Agent | 生成页面讲解稿、过渡话术和不同受众版本。 |
| Question Classifier Agent | 判断客户问题的产品、技术、商务、交付、竞品或风险类型。 |
| Answer Agent | 基于授权资料生成带来源的回答。 |
| Commitment Guard Agent | 检查价格、周期、能力、合规和竞品承诺风险。 |
| Meeting Recorder Agent | 生成转写摘要、需求、异议和跟进任务。 |
| Quality Judge Agent | 检查讲解和回答的来源、准确性、完整性和风险。 |

### 8.2 Agent 输出约束

Agent 输出必须包含：

- 内容类型：讲解、回答、过渡、风险提示或会后摘要。
- 来源：PPT 页码、产品资料、案例或规则文档。
- 置信度：高、中、低。
- 是否需要人工确认。
- 是否允许自动播报。
- 建议展示页面或下一步动作。

### 8.3 讲解稿协议

```json
{
  "slide_number": 4,
  "duration_seconds": 90,
  "opening": "这一页先说明系统如何接入现有业务数据。",
  "talking_points": [
    "说明数据接入方式",
    "强调权限隔离",
    "结合客户当前系统给出对应价值"
  ],
  "transition": "接下来介绍数据进入系统后的处理流程。",
  "sources": [
    {
      "type": "ppt_slide",
      "document_id": 12,
      "slide_number": 4
    }
  ],
  "risk_level": "low",
  "requires_human_confirmation": false
}
```

### 8.4 实时问答流程

```text
语音/文字输入
  -> ASR 或文本清洗
  -> 问题分类
  -> 当前页面和客户上下文检索
  -> 产品能力、案例、交付规则检索
  -> 回答生成
  -> 来源与承诺风险检查
  -> 人工确认或播报
  -> 记录回答和反馈
```

## 9. 页面和模块设计

### 9.1 客户与商机

列表必须支持客户名称、行业、负责人、商机阶段、更新时间和分页查询。

详情包括：客户画像、联系人、需求、历史会议、演示记录、已生成材料和跟进任务。

### 9.2 产品资料库

- 产品列表和版本列表。
- PPT 上传和解析进度。
- 页面缩略图和页面详情。
- 页面讲解稿和 FAQ。
- 产品能力、限制条件、指标有效期。
- 审核、发布、归档和版本对比。

### 9.3 演示准备页

区域包括：

- 客户和商机选择。
- 产品及 PPT 版本选择。
- 演示目标和预计时长。
- 页面路线和拖拽排序。
- AI 推荐的案例、问题和风险。
- 讲解稿预览和人工编辑。
- 演示前检查清单。

### 9.4 演示工作台

页面布局：

- 左侧：页面缩略图、页码和页面状态。
- 中间：当前 PPT 页面和演示区域。
- 右侧：讲解稿、客户问题、回答建议、来源和风险提示。
- 底部：开始、暂停、上一页、下一页、跳页、重新讲解、人工接管。

必须展示：

- 当前页/总页数。
- 讲解状态、录音状态和播报状态。
- 当前回答是否经过人工确认。
- 当前内容的来源和有效期。
- 会话断线和模型异常提示。

### 9.5 会后复盘页

- 会议转写。
- 讲解页面和客户停留时间。
- 客户问题和回答。
- 需求、异议、竞争信息和待确认事项。
- AI 生成的会议纪要。
- 跟进任务、负责人和截止时间。
- 人工编辑、确认和导出。

- 业务表使用独立自增主键，删除优先使用归档或状态删除。

## 11. 状态设计

### 11.1 PPT 状态

`uploading`、`parsing`、`pending_review`、`approved`、`published`、`archived`、`failed`。

### 11.2 演示计划状态

`draft`、`preparing`、`ready`、`in_progress`、`completed`、`cancelled`、`failed`。

### 11.3 演示会话状态

`created`、`ready`、`presenting`、`paused`、`answering`、`human_takeover`、`ending`、`completed`、`interrupted`。

### 11.4 回答状态

`draft`、`generated`、`pending_approval`、`approved`、`spoken`、`rejected`、`failed`。

高风险回答必须经过 `pending_approval -> approved`，不能直接进入 `spoken`。

## 12. 接口设计

以下为目标接口，接口必须统一返回请求追踪 ID、错误码和消息；分页接口返回 `rows`、`total`、`page`、`page_size`。

### 12.1 客户和商机

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/v1/customers` | 分页查询客户。 |

## 14. 风险与安全控制

### 14.1 产品事实风险

- 回答必须引用当前有效的产品版本或审核资料。
- 过期资料不能作为默认来源。
- 找不到证据时必须回答“当前资料无法确认”，并建议人工确认。
- 模型不能补充不存在的指标、接口、客户案例或产品能力。

### 14.2 商业承诺风险

以下内容默认不允许自动播报：

- 价格、折扣和付款条件。
- 交付周期和资源投入。
- 定制开发范围和上线承诺。
- 安全认证、合规结论和法律表述。
- 对竞品的绝对性评价。
- 未经审核的客户案例和效果数据。

系统应显示“需要人工确认”，并提供审核、修改、拒绝和接管操作。

### 14.3 客户数据安全

- 客户资料、联系人、录音、转写和会议纪要按组织和客户范围隔离。
- 语音和文本进入模型前执行敏感信息识别和脱敏。
- 对象存储使用短时授权访问。
- 会议数据提供保留周期、导出和删除策略。
- 任何对外展示的资料必须标识来源版本。

### 14.4 Prompt Injection 防护

PPT 文本、客户问题、会议转写和外部文档都属于不可信输入。它们不能改变系统规则、工具权限、权限边界或回答协议。系统提示、工具策略和业务规则必须与外部内容隔离。

## 15. 异常与降级

| 场景 | 处理方式 |
|---|---|
| PPT 上传失败 | 显示具体文件错误，保留失败记录，可重新上传。 |
| PPT 解析失败 | 允许下载原文件，标记失败页面，不生成虚假讲解稿。 |
| 语音识别失败 | 显示文字输入入口，允许人工输入问题。 |
| 语音播报失败 | 展示文字讲解稿，允许售前人员手动讲解。 |
| 模型超时 | 使用备用模型或返回人工接管，不自动播报未完成答案。 |
| 知识库无答案 | 明确提示资料不足，生成待确认事项。 |
| 外部会议中断 | 保存本地操作事件，恢复后补传；无法恢复时允许导出本地记录。 |
| 权限失效 | 终止敏感操作，保留已完成会话记录。 |
| 回答风险过高 | 阻止自动播报，要求人工审核。 |
| 会议纪要生成失败 | 保留转写内容，允许人工编辑和手动创建任务。 |

## 16. 非功能需求

### 16.1 实时性

- 页面翻页操作应立即响应。
- 语音识别应支持流式中间结果。
- 普通客户问题应显示处理中状态，并支持取消。
- 回答生成、风险检查和语音合成阶段分别展示状态。

### 16.2 稳定性

- 演示会话支持心跳、断线重连和事件幂等。
- 翻页、暂停、接管和结束操作必须可追踪。
- 语音、模型和知识库服务任一失败不应导致 PPT 无法查看。
- 会话结束后异步生成纪要，失败可以独立重试。

### 16.3 可观测性

记录演示会话、页面停留、讲解时长、客户问题、回答来源、人工接管、风险拦截和模型耗时。

指标包括：

- PPT 解析成功率。
- 讲解稿审核通过率。
- 语音识别成功率。
- 客户问题回答命中率。
- 来源支持率。
- 人工接管率。
- 高风险回答拦截率。
- 会议纪要确认率。
- 演示完成率和平均时长。

## 17. 评测与验收

### 17.1 离线评测

评测集覆盖：

- 文本型、图表型、图片型和复杂布局 PPT。
- 产品介绍、行业方案、技术架构和案例演示。
- 客户产品、技术、商务、交付和竞品问题。
- 已知答案、资料不足、过期资料和恶意提示注入。
- 中文、英文和中英混合会议内容。

### 17.2 评测指标

- 页面结构解析准确率。
- 页面标题和关键内容识别准确率。
- 讲解稿事实准确率。
- 讲解稿来源支持率。
- 问题分类准确率。
- 客户问题回答正确率。
- 高风险内容拦截率。
- 人工接管建议准确率。
- 会议纪要需求和任务提取准确率。
- 语音识别词错率和播报可用率。

### 17.3 验收标准

1. 未发布 PPT 不能被默认用于对外自动讲解。
2. 每条讲解稿和回答都能追溯到有效来源或明确标记为待确认。
3. 价格、交付和合规等高风险内容不会未经确认自动播报。
4. 客户问题无法回答时不会生成虚构结论。
5. 售前人员可以随时暂停、跳页、人工接管和恢复演示。
6. 网络、语音或模型服务异常时仍可查看 PPT 和阅读讲解稿。
7. 客户资料和会议内容不会跨组织或客户范围泄露。
8. 会后纪要、问题和跟进任务能够由人工确认后保存。

## 18. 部署架构

```text
Web / Mobile / Meeting Client
             |
        API Gateway
             |
Presentation Service ---- PostgreSQL
       |                  Object Storage
       |                  Redis / Queue
       v
Presentation Worker
  |-- PPT Parser
  |-- Context Retriever
  |-- Agent Runtime
  |-- ASR / TTS Adapter
  |-- Risk Guard
  |-- Summary Worker
```

要求：

- API、PPT 解析、Agent、语音和报告 Worker 可独立扩缩容。
- 音频和 PPT 解析使用隔离运行环境。
- 外部模型、ASR、TTS 和对象存储通过适配层接入。
- 语音流和页面控制支持独立链路，避免语音故障阻塞演示控制。
- 生产环境使用密钥管理服务，不在配置文件提交 Token 或 API Key。
