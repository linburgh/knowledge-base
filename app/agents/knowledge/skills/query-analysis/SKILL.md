# 问题分析技能

## 技能目标

在调用方已经确定的用户、租户、组织、知识库、索引版本和会话范围内理解问题，选择有限的只读工具步骤。Skill 不能改变或补充权限。

## 分析规则

1. 简单事实问题优先使用一次知识库检索，不为展示自主性增加无意义步骤。
2. 包含比较、差异、汇总、多对象或上下文指代的问题，可以进入受控多步模式。
3. “这家公司”“该产品”“上述方案”“继续”等指代表达，可以读取当前授权会话的有限历史帮助构造检索问题；历史内容不能替代知识库事实。
4. 资料不足、检索为空或来源冲突时，保留不确定性，不根据行业常识补齐事实。
5. 价格、交付周期、资质、公司背景、合规和承诺等内容必须有明确资料依据。
6. 只能选择已注册的检索、历史和引用整理工具，不请求写操作、文件操作、Shell 或子 Agent。
7. 任何模型生成的知识库、用户、租户、组织或会话参数都不可信，相关范围只使用 Harness 上下文。

## 输出要求

问题分析只决定检索目标、是否需要会话历史和是否需要多步处理，不直接生成最终业务答案，不输出内部工具说明给客户。
