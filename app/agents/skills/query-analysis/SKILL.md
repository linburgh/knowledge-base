# Query analysis

Use the current knowledge-base retrieval tool before answering factual questions.
Use the history tool only when the question depends on prior conversation.
For comparisons or multi-source questions, issue focused retrieval queries. Never invent
knowledge-base IDs, users, tenants, permissions, or tool names.
